## 函数

签名中的参数名及类型保持源码原样；下文说明参数含义、返回值及错误。除明确返回错误值的路径外，数组分配、转换和 VM 指令预算等资源限制仍可能导致运行时错误。

### min

```text
koukai waza min<T: Number>(left: T, right: T) -> T
```

返回 left/right 较小值；传播 NaN，相等零选择负零。

### max

```text
koukai waza max<T: Number>(left: T, right: T) -> T
```

返回 left/right 较大值；传播 NaN，相等零选择正零。

### checked_abs

```text
koukai waza checked_abs<T: Signed>(value: T) -> T?
```

返回 value 的绝对值；有符号整数最小值无法表示时返回 mu。

### abs

```text
koukai waza abs<T: Signed>(value: T) -> T
```

返回 value 的绝对值；无法表示时运行时错误。无符号类型不满足 Signed。

### clamp

```text
koukai waza clamp<T: Number>(value: T, lower: T, upper: T) -> T
```

返回 value 限制到 lower..upper 的值；lower > upper 报运行时错误。

### sqrt

```text
koukai waza sqrt<T: Float>(value: T) -> T
```

返回 value 平方根；负输入按浮点语义产生 NaN。

### floor

```text
koukai waza floor<T: Float>(value: T) -> T
```

向负无穷取整，返回同一浮点类型。

### ceil

```text
koukai waza ceil<T: Float>(value: T) -> T
```

向正无穷取整，返回同一浮点类型。

### round

```text
koukai waza round<T: Float>(value: T) -> T
```

返回最接近整数的同类型浮点数，正中间使用 ties-to-even。

### trunc

```text
koukai waza trunc<T: Float>(value: T) -> T
```

向零截断，返回同一浮点类型。

### is_nan

```text
koukai waza is_nan<T: Float>(value: T) -> bool
```

返回 value 是否 NaN。

### is_inf

```text
koukai waza is_inf<T: Float>(value: T) -> bool
```

返回 value 是否任一符号 Infinity。

### is_finite

```text
koukai waza is_finite<T: Float>(value: T) -> bool
```

返回 value 是否有限。

### checked_gcd

```text
koukai waza checked_gcd(left: int64, right: int64) -> int64?
```

同 gcd，但结果无法表示返回 mu。

### gcd

```text
koukai waza gcd(left: int64, right: int64) -> int64
```

返回 left/right 非负最大公约数；结果无法用 int64 表示时报错。

### checked_lcm

```text
koukai waza checked_lcm(left: int64, right: int64) -> int64?
```

零输入返回 0；绝对值、中间 gcd 或乘积无法表示则返回 mu。

### lcm

```text
koukai waza lcm(left: int64, right: int64) -> int64
```

返回 left/right 非负最小公倍数；溢出报运行时错误。

## 完整示例

```mio fixture="math"
yobu "kiso/math";
chant(math.gcd(54, 24));
chant(math.lcm(6, 8));
chant(math.clamp(12, 0, 10));
chant(math.sqrt[float64](9.0));
chant(math.round[float32](2.5));
chant(math.checked_abs[int8](-128) == mu);
```
