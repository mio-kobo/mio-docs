严格 UTF-8 与 Unicode 标量编解码，不处理显示宽度、字素簇或规范化。U+FFFD 本身是合法标量，不能只看 value 判断解码失败，应看 valid。

支持范围：本页示例通过 Go 引导 CLI / Mochi VM 验证；错误分支覆盖范围见 [验证报告](/docs/tooling/verification)，不表示每个函数的每条分支均实测。Native AOT 与纯 Mio 后端需按 [当前阶段](/docs/native-aot) 单独评估。

## 公开类型与常量

以下为源码声明，属于签名资料，不是完整可执行程序。

```text
koukai kata DecodeResult {
    value: rune;
    width: int64;
    valid: bool;
}
```

## 函数

签名中的参数名及类型保持源码原样；下文说明参数含义、返回值及错误。除明确返回错误值的路径外，数组分配、转换和 VM 指令预算等资源限制仍可能导致运行时错误。

### is_valid_rune

```text
koukai waza is_valid_rune(value: rune) -> bool
```

检查 value 是否为 Unicode 标量值。

### rune_width

```text
koukai waza rune_width(value: rune) -> int64
```

返回合法 value 的 1..4 字节编码长度；非法标量报运行时错误。

### decode_one

```text
koukai waza decode_one(data: []uint8, offset: int64) -> DecodeResult
```

从 data 的字节 offset 解码一个标量。成功 width=1..4、valid=hai；非法序列 value=U+FFFD、width=1、valid=iie；正好末尾 width=0；其他越界 offset 报运行时错误。

### encode_rune

```text
koukai waza encode_rune(value: rune) -> []uint8
```

将 value 编码为新 UTF-8 字节数组；负值、代理区或大于 U+10FFFF 报运行时错误。

### append_rune

```text
koukai waza append_rune(destination: []uint8, value: rune) -> unit
```

将 value 编码追加至 destination；非法标量在修改目标前报错。

### valid

```text
koukai waza valid(data: []uint8) -> bool
```

返回 data 是否是严格合法的 UTF-8。

### rune_count

```text
koukai waza rune_count(data: []uint8) -> int64?
```

合法 data 返回标量数量，非法数据返回 mu。

## 完整示例

```mio fixture="utf8"
yobu "kiso/utf8";
kaku data = utf8.encode_rune('澪');
kaku result = utf8.decode_one(data, 0);
chant(result.valid);
chant(result.width);
chant(result.value);
kaku end = utf8.decode_one(data, len(data));
chant(end.width);
kaku invalid: []uint8 = [255];
chant(utf8.rune_count(invalid) == mu);
```
