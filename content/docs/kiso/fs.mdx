同步宿主文件系统 API。CLI 默认注册 NativeFS，权限与进程相同。File 使用受信任 resource；错误通过结果字段返回，不使用异常。流偏移单位均为字节。

支持范围：本页示例通过 Go 引导 CLI / Mochi VM 验证；错误分支覆盖范围见 [验证报告](/docs/tooling/verification)，不表示每个函数的每条分支均实测。Native AOT 与纯 Mio 后端需按 [当前阶段](/docs/native-aot) 单独评估。

## 公开类型与常量

以下为源码声明，属于签名资料，不是完整可执行程序。

```text
koukai sentaku FsError {
    NotFound(string);
    PermissionDenied(string);
    Closed(string);
    InvalidArgument(string);
    NoSpace(string);
    InvalidPath(string);
    IOFailure(string);
}

koukai kata File { handle: resource; }

koukai kata FileResult { file: File?; error: FsError?; }

koukai kata ReadAllResult { data: []uint8; error: FsError?; }

koukai kata UnitResult { error: FsError?; }

koukai kata StatResult { exists: bool; is_file: bool; is_dir: bool; error: FsError?; }

koukai kata DirEntry { name: string; is_file: bool; is_dir: bool; }

koukai kata DirResult { entries: []DirEntry; error: FsError?; }
```

## 函数

签名中的参数名及类型保持源码原样；下文说明参数含义、返回值及错误。除明确返回错误值的路径外，数组分配、转换和 VM 指令预算等资源限制仍可能导致运行时错误。

### open_read

```text
koukai waza open_read(path: string) -> FileResult
```

按 path 只读打开，返回 FileResult；失败 file=mu。

### open_write

```text
koukai waza open_write(path: string) -> FileResult
```

按 path 创建或截断写入，返回 FileResult。

### open_append

```text
koukai waza open_append(path: string) -> FileResult
```

按 path 创建或追加写入，返回 FileResult。

### read

```text
koukai waza read(file: File, destination: []uint8, offset: int64, length: int64) -> io.ReadResult
```

读取到 destination 的 offset/length 区间，返回 io.ReadResult；非法区间返回 InvalidArgument，关闭句柄返回 Closed，其他宿主错误映射为 Other(message)。

### write

```text
koukai waza write(file: File, source: []uint8, offset: int64, length: int64) -> io.WriteResult
```

将 source 的 offset/length 区间写入 file，返回 io.WriteResult；允许部分写，错误映射同 read。

### close

```text
koukai waza close(file: File) -> UnitResult
```

关闭 file，返回 UnitResult；复制的 File 共享关闭状态，重复关闭返回 Closed。

### reader

```text
koukai waza reader(file: File) -> io.Reader
```

将 file 适配为 io.Reader，不转移/自动关闭句柄。

### writer

```text
koukai waza writer(file: File) -> io.Writer
```

将 file 适配为 io.Writer，不转移/自动关闭句柄。

### read_all

```text
koukai waza read_all(path: string) -> ReadAllResult
```

按 path 打开、32768 字节分块读并关闭，返回 data/error；读取错误可带已读前缀，成功后关闭错误也返回。

### write_all

```text
koukai waza write_all(path: string, data: []uint8) -> UnitResult
```

按 path 创建或截断，完整写入 data 并关闭；写入错误优先，否则返回关闭结果。

### stat

```text
koukai waza stat(path: string) -> StatResult
```

返回 path 的 exists/is_file/is_dir；NotFound 转为 exists=iie 且 error=mu，其他错误保留。

### exists

```text
koukai waza exists(path: string) -> bool
```

返回 stat(path).exists；便捷 bool 会丢弃详细错误，需区分失败时用 stat。

### is_file

```text
koukai waza is_file(path: string) -> bool
```

返回 stat(path).is_file；详细错误需用 stat。

### is_dir

```text
koukai waza is_dir(path: string) -> bool
```

返回 stat(path).is_dir；详细错误需用 stat。

### create_dir

```text
koukai waza create_dir(path: string) -> UnitResult
```

为 path 创建单级目录，返回 UnitResult；不递归创建父目录。

### read_dir

```text
koukai waza read_dir(path: string) -> DirResult
```

返回 path 目录项数组与错误，使用资源迭代器并关闭；不要依赖未承诺的排序。

## 完整示例

```mio fixture="fs"
yobu "kiso/fs";
yobu "kiso/string";
kaku written = fs.write_all("sample.txt", string.to_bytes("Mio"));
chant(written.error == mu);
kaku loaded = fs.read_all("sample.txt");
chant(loaded.error == mu);
chant(len(loaded.data));
chant(fs.is_file("sample.txt"));
kaku opened = fs.open_read("sample.txt");
kaku file = opened.file;
moshi (file != mu) {
    kaku active = file;
    kaku first = fs.close(active);
    chant(first.error == mu);
    kaku second = fs.close(active);
    chant(second.error != mu);
}
```

预期 stdout（逐字节匹配，末尾有换行）：

```text title="output"
hai
hai
3
hai
hai
hai
```

文件例子以验证器的独立临时工作目录执行，创建 sample.txt，不会覆盖用户文件。fs 不提供本页未列出的递归建目录、删除、监听或异步 API。
