通用动态数组，遵守共享引用语义。VM 的数组分配有资源上限，容量不是无限承诺。普通源码不能直接调用私有 intrinsic。

支持范围：本页示例通过 Go 引导 CLI / Mochi VM 验证；错误分支覆盖范围见 [验证报告](/docs/tooling/verification)，不表示每个函数的每条分支均实测。Native AOT 与纯 Mio 后端需按 [当前阶段](/docs/native-aot) 单独评估。

## 函数

签名中的参数名及类型保持源码原样；下文说明参数含义、返回值及错误。除明确返回错误值的路径外，数组分配、转换和 VM 指令预算等资源限制仍可能导致运行时错误。

### make

```text
koukai waza make<T>(length: int64, initial: T) -> []T
```

`length` 个元素，均初始化为 `initial`。若 initial 含引用，各元素仍共享该引用。负长度、容量溢出或资源不足报运行时错误。

### with_capacity

```text
koukai waza with_capacity<T>(capacity: int64) -> []T
```

为元素类型 T 创建长度 0、预留 capacity 的数组；类型不能推断时用 `[T]`。负容量或超限报错。

### push

```text
koukai waza push<T>(values: []T, value: T) -> unit
```

向 values 原地追加 value，返回 unit；别名可见，必要时扩容。资源不足报错。

### capacity

```text
koukai waza capacity<T>(values: []T) -> int64
```

返回 values 已分配元素容量，不是长度。

### reserve

```text
koukai waza reserve<T>(values: []T, additional: int64) -> unit
```

确保可额外容纳 additional 个元素，不改变长度与已有内容；additional 不能为负，溢出或超限报错。

### clone

```text
koukai waza clone<T>(values: []T) -> []T
```

返回独立后备数组，浅复制元素；嵌套引用仍共享，分配受资源上限约束。

### truncate

```text
koukai waza truncate<T>(values: []T, new_length: int64) -> unit
```

将共享长度缩到 new_length，保留容量；必须在 0 与原长度之间，否则报错。

### append_all

```text
koukai waza append_all<T>(destination: []T, source: []T) -> unit
```

向 destination 批量追加 source 当前元素；支持自追加，按追加前长度处理，溢出或资源不足报错。

## 完整示例

```mio fixture="arrays"
yobu "kiso/array";
kaku original = [1, 2];
kaku alias = original;
alias[0] = 9;
array.push(alias, 3);
chant(original[0]);
chant(len(original));
kaku copied = array.clone(original);
copied[0] = 7;
chant(original[0]);
array.append_all(original, original);
chant(len(original));
array.truncate(alias, 1);
chant(len(original));
```

预期 stdout（逐字节匹配，末尾有换行）：

```text title="output"
9
3
9
6
1
```
