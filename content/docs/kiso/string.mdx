本模块提供基于 UTF-8 字节语义的查找、转换与 StringBuilder。它不处理 Unicode 规范化、大小写折叠或字素簇；所有索引与容量单位均为字节。Builder 值复制时共享底层 buffer。

本页示例通过 Go 引导 CLI / Mochi VM 验证。错误分支的覆盖范围见 [验证报告](/docs/tooling/verification)，并非每个函数的每条分支都经过实测。Native AOT 与纯 Mio 后端的支持情况需按 [当前阶段](/docs/native-aot) 单独评估。

## 公开类型与常量

以下为源码中的声明，属于签名资料，不是完整可执行程序。

```text
koukai kata StringBuilder { buffer: bytes.ByteBuffer; }
```

## 函数

签名中的参数名及类型保持源码原样；下文说明参数含义、返回值及错误。除明确返回错误值的路径外，数组分配、转换和 VM 指令预算等资源限制仍可能导致运行时错误。

### to_bytes

```text
koukai waza to_bytes(value: string) -> []uint8
```

将 value 的 UTF-8 字节复制到新数组。修改返回的数组不会影响原字符串。

### from_utf8

```text
koukai waza from_utf8(data: []uint8) -> string?
```

严格校验 data。合法时返回独立的字符串副本，非法时返回 mu。

### byte_len

```text
koukai waza byte_len(value: string) -> int64
```

返回 value 的字节数，时间复杂度 O(1)。

### rune_count

```text
koukai waza rune_count(value: string) -> int64
```

返回 Unicode 标量值数量。若宿主传入非法 UTF-8 字符串，会产生运行时错误。

### has_prefix

```text
koukai waza has_prefix(value: string, prefix: string) -> bool
```

按字节比较 value 是否以 prefix 开头。

### has_suffix

```text
koukai waza has_suffix(value: string, suffix: string) -> bool
```

按字节比较 value 是否以 suffix 结尾。

### index

```text
koukai waza index(value: string, pattern: string) -> int64
```

返回 pattern 在 value 中首次出现的 UTF-8 字节偏移。未找到时返回 -1，空 pattern 返回 0。

### contains

```text
koukai waza contains(value: string, pattern: string) -> bool
```

返回 value 是否包含 pattern。空模式返回真。

### concat

```text
koukai waza concat(left: string, right: string) -> string
```

返回 left 与 right 拼接后的独立字符串。

### new_builder

```text
koukai waza new_builder() -> StringBuilder
```

返回一个空的 StringBuilder。

### builder_with_capacity

```text
koukai waza builder_with_capacity(capacity: int64) -> StringBuilder
```

创建空 Builder，并按字节预留指定容量。负容量或资源不足时会报错。

### write_string

```text
koukai waza write_string(builder: StringBuilder, value: string) -> unit
```

将 value 的字节追加到 builder，返回 unit。

### write_rune

```text
koukai waza write_rune(builder: StringBuilder, value: rune) -> unit
```

将 value 编码后追加到 builder。非法 Unicode 标量值会导致运行时错误。

### builder_len

```text
koukai waza builder_len(builder: StringBuilder) -> int64
```

返回当前 builder 的字节长度。

### builder_capacity

```text
koukai waza builder_capacity(builder: StringBuilder) -> int64
```

返回 builder 的字节容量。

### builder_reset

```text
koukai waza builder_reset(builder: StringBuilder) -> unit
```

将共享 buffer 的长度置零，并保留容量。

### builder_string

```text
koukai waza builder_string(builder: StringBuilder) -> string
```

返回独立的不可变字符串副本。若外部污染 buffer 使其成为非法 UTF-8，会报运行时错误。

## 完整示例

```mio fixture="string"
yobu "kiso/string";
chant(string.byte_len("澪A"));
chant(string.rune_count("澪A"));
chant(string.index("澪A", "A"));
kaku builder = string.new_builder();
string.write_string(builder, "Mio");
string.write_rune(builder, '!');
chant(string.builder_string(builder));
kaku invalid: []uint8 = [255];
chant(string.from_utf8(invalid) == mu);
```
