title: 数组与空值
description: 访问一组值，理解共享引用与可空类型。
---

## 完整程序

```mio title="collections.mio"
kaku values = [10, 20, 30];
kaku alias = values;
alias[1] = 25;
chant(values[1]);
chant(len(values));

kaku answer: int64? = mu;
answer = values[0];
moshi (answer != mu) {
    chant(answer + 1);
}
```

```text title="output"
25
3
11
```

## 逐步理解

数组下标从 0 开始。`values[1]` 指向第二个元素，`len(values)` 返回元素数量。

数组采用共享引用语义。`alias` 与 `values` 指向同一组元素，因此通过 `alias` 修改第二个元素后，从 `values` 读取也得到 25。赋值不会复制数组。

`int64?` 表示整数或空值 `mu`。使用 `answer != mu` 检查后，在对应的真分支里，可靠变量引用被收窄为非空整数，才可以执行加法。不要把这里的收窄泛化为任何数组索引表达式都能持久收窄。

## 练习

把 `alias[1] = 25;` 改为 `alias[0] = 40;`，其他代码不变。

预期输出 `20`、`3`、`41`。第二个元素没有改变；最后一行使用的是第一个元素。

## 常见错误

- 读取 `values[3]`：长度为 3 的数组最大有效下标是 2，越界会产生运行时错误。
- 在检查前直接计算 `answer + 1`：可空类型不能未经收窄参与普通整数运算。
- 写 `kaku answer = mu;`：无法仅凭空值推断目标类型，必须提供明确的可空类型。
