## 如何使用示例

把每一课的完整代码分别保存为一个 `.mio` 文件，然后执行：

```sh
./mio check path/to/lesson.mio
./mio run path/to/lesson.mio
```

不要把多课程序同时粘贴到同一文件里。包级声明可能重名；每个示例应独立运行。

教程基于核心提交 `51f1ba883767c1fc08ba415fbb0075316ff03106`。示例使用 Go 引导 CLI 执行，输出由本地实测获得。验证使用该提交的隔离、无本地改动源码快照，不包含相邻工作树的 M17e 改动；未对原生自举、WebAssembly 或性能作发布结论。
