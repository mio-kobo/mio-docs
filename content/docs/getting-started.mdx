description: 从核心仓库构建 Mio CLI。
---

以下命令来自核心 README 的源码构建流程；开发版使用 `Mio-2`。

```sh
git clone --branch Mio-2 https://github.com/mio-kobo/mio.git
cd mio
go build -o mio ./cmd/mio
./mio version
```

创建 `hello.mio`：

```mio
chant("Hello, Mio!");
```

```sh
./mio check hello.mio
./mio run hello.mio
./mio build hello.mio
./mio exec hello.mochi
```

请保留 `bunko/`；必要时通过 `MIO_BUNKO` 指定标准库根目录。
