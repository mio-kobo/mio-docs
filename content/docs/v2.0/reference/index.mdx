## 阅读规则

语法资料中的方括号表示可选部分时会明确说明；完整程序使用 Mio 代码块，并通过 WebAssembly Playground 显示实际运行结果，签名资料不是独立程序。静态错误表示 `check` 阶段拒绝；运行时错误表示实际执行失败，不把二者混为语法错误。

本文档统一使用“可空类型（Nullable）”“包（按目录组织的导入单元）”“Bunko（标准库物理根）”“Kiso（公开 kiso/ 路径）”。Mochi 文件格式版本与 Mio 语言版本独立，VM 与原生后端规则分开。

验证依据与未覆盖范围见 [验证说明](/docs/v2.0/tooling/verification)。
