## 语法与表达式

Mio 使用日语罗马字关键字、分号结尾的语句及大括号代码块。源码采用 UTF-8 编码，但普通标识符目前只允许 ASCII 英文字母、数字和下划线。

### 程序与语句

普通语句以分号 `;` 结尾，函数、条件语句和循环语句的代码块结束后不需要额外分号。

```mio title="Syntax.mio"
kaku count: int64 = 2;
teisu limit: int64 = 5;

moshi (count < limit) {
    chant("小于上限");
}
```

`kaku` 声明可变变量，`teisu` 声明编译期常量。两者都必须初始化；`teisu` 应在文件顶层声明。`=` 用于赋值语句，不是可嵌套的赋值表达式。

### 保留关键字

| 关键字 | 作用 | 关键字 | 作用 |
| --- | --- | --- | --- |
| `kaku` | 变量 | `teisu` | 常量 |
| `waza` | 函数 | `kaesu` | 返回 |
| `moshi` | 条件成立分支 | `sore` | 否则分支 |
| `aida` | 条件循环 | `nukeru` | 退出循环 |
| `tsuzuku` | 继续下一轮 | `hai` | 真 |
| `iie` | 假 | `mu` | 空值 |
| `kata` | 结构体 | `sentaku` | 枚举 |
| `awase` | 枚举匹配 | `baai` | 匹配分支 |
| `yobu` | 导入包 | `koukai` | 公开声明 |

`chant`、`len` 及 `int64`、`string` 等类型名称并非上述保留关键字，但属于已有接口或类型名称，不建议拿来命名其他声明。

### 注释

Mio 支持 `//` 单行注释和 `/* ... */` 块注释。

```mio title="Comment.mio"
// 这里保存需要输出的数值
kaku number = 42;

/* 可以使用块注释
   解释较长的代码。 */
chant(number);
```

### 字面量

| 类型 | 示例 | 说明 |
| --- | --- | --- |
| 整数 | `42`、`0` | 十进制；非零整数不能带多余前导零 |
| 浮点数 | `3.14`、`2.5e-2` | 小数或科学计数法 |
| 字符串 | `"Mio"` | 双引号、UTF-8 文本 |
| 字符 | `'A'`、`'中'` | 单个 Unicode 标量值，类型为 `rune` |
| 布尔值 | `hai`、`iie` | `bool` 类型 |
| 空值 | `mu` | 在可空类型上下文中表示不存在的值 |
| 数组 | `[1, 2, 3]` | 元素类型统一的数组 |

字符串支持 `\n`、`\r`、`\t`、`\"` 与 `\\` 转义。字符字面量还支持 `\xNN`、`\uNNNN`、`\UNNNNNNNN` 等形式。源码中的负数由一元负号与数值字面量组成。

### 运算符与优先级

| 优先级（由高到低） | 运算符或形式 | 说明 |
| --- | --- | --- |
| 1 | `.` | 成员访问 |
| 2 | `[]` | 数组或 Map 索引访问 |
| 3 | `()` | 函数调用 |
| 4 | 一元 `-`、`!` | 数值取负、逻辑非 |
| 5 | `*`、`/` | 乘法、除法 |
| 6 | `+`、`-` | 加法、减法 |
| 7 | `<`、`<=`、`>`、`>=` | 数值大小比较 |
| 8 | `==`、`!=` | 相等性比较 |
| 9 | `&&` | 逻辑与 |
| 10 | `\|\|` | 逻辑或 |

同一优先级的二元运算通常从左向右结合，括号可改变运算顺序。`&&` 与 `||` 采用短路求值。

```mio title="Operator.mio"
chant(2 + 3 * 4);
chant((2 + 3) * 4);
chant(hai && !iie);
```

数值类型必须匹配；字符串不支持直接使用 `+` 拼接。Mio V2.0 也不支持 `%`、`++`、`--`、`+=` 或位运算符作为普通语言运算符。

### 条件语句

`moshi` 的条件必须是 `bool` 类型，不能直接使用整数代替布尔表达式。

```mio title="Condition.mio"
kaku score = 75;

moshi (score >= 90) {
    chant("优秀");
} sore {
    moshi (score >= 60) {
        chant("及格");
    } sore {
        chant("未及格");
    }
}
```

Mio V2.0 不提供独立的 `sore moshi` 连续分支语法；需要多分支时在 `sore` 代码块中嵌套 `moshi`。

### 循环语句

`aida` 在每一轮执行前检查 `bool` 条件。`nukeru` 结束当前最内层循环；`tsuzuku` 跳过本轮剩余语句，再检查条件。

```mio title="Loop.mio"
kaku index = 0;

aida (index < 5) {
    index = index + 1;
    moshi (index == 2) { tsuzuku; }
    moshi (index == 5) { nukeru; }
    chant(index);
}
```

当前没有单独的 C 风格 `for` 或 `for...in` 循环语法。

### 枚举模式匹配

`awase` 只能用于枚举值；每个 `baai` 必须匹配已声明变体，关联数据的绑定数量必须正确，所有变体均须覆盖。

```mio title="Match.mio"
sentaku State {
    Waiting;
    Finished(int64);
}

waza show(state: State) -> unit {
    awase (state) {
        baai Waiting { chant("等待中"); }
        baai Finished(value) { chant(value); }
    }
}

show(State.Finished(42));
```

枚举声明、构造及穷尽匹配的更多规则见 [集合与自定义类型](/docs/v2.0/reference/collections)。
