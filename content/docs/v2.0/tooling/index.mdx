编辑器是独立项目，其源码版本不等于核心版本。VS Code 源码清单为 `0.3.0`，JetBrains 源码清单为 `0.6.1`；本轮没有运行 IDE 客户端端到端验收，也没有查询市场当前发布状态。不要把插件市场版本直接等同于 Mio 核心版本。

官方 v2.0.0 发行包包含：

```text
mio                  # 源码前端、Mochi 编译器、VM、LSP
mochi-aot            # Go AOT 后端
mochi-aot-audit      # 只读 Mochi 指令/缺口扫描
native-aot           # 纯 Mio Native AOT 编译器（M18 Stage 4）
native-aot.mochi     # native-aot 自身的 Mochi 输入
bunko/               # 标准库物理根
```

`mio build` 生成 Mochi 字节码；`mochi-aot` 与 `native-aot` 才生成 ARM64 Mach-O。原生工具的平台、签名和 config 文件协议见 [Native AOT](/docs/v2.0/internals/native-aot)。
