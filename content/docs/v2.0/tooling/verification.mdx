## 本轮实际执行

环境：macOS 15.6.1 ARM64，Apple Silicon；官方发行包通过 GitHub Release 下载。

### 发行包与安装

```sh
shasum -a 256 -c SHA256SUMS
file "$MIO_HOME/mio"
codesign --verify --strict "$MIO_HOME/mio"
"$MIO_HOME/mio" version
```

结果：

- 归档 SHA256 与 `SHA256SUMS` 一致；
- 四个工具均为 `Mach-O 64-bit executable arm64`；
- `mio` 的 strict codesign 验证通过；
- `mio version` 输出 `Mio 2.0.0`。

### Mochi VM 路径

实际执行：

```sh
mio check hello.mio
mio run hello.mio
mio build -o hello.mochi hello.mio
mio exec hello.mochi
mio disasm hello.mochi
```

结果：

- `check` 输出 `check passed`；
- `run` / `exec` 输出 `Hello, Mio!`；
- `build` 成功且无 stdout；
- `disasm` 输出 globals、constants、instructions 与 functions。

同时执行了 `math`、`array`、`string`、`convert`、`fs`、`binary` 六个 Bunko 示例，stdout 与本页正文一致。

### 测试与诊断

```sh
mio test ./testing/mathdemo
mio test ./testing/mathdemo --format=json
mio test ./testing/mathdemo --run='^test_add$'
mio check --format=json --color=never bad.mio
mio check --format=short --color=never bad.mio
```

结果：

- 测试报告 2 passed / 0 failed；JSON 含 `schema_version`、`packages`、`summary`；
- 筛选执行 1 个测试；
- 类型错误返回退出码 `1`，短格式为 `bad.mio:1:17: error[E0301]...`；
- 未知命令返回 `2`。

教程验证器：

```sh
DOCS_VERSION=v2.0 MIO_CLI="$MIO_HOME/mio" MIO_BUNKO="$MIO_HOME/bunko" \
  node scripts/check-examples.mjs
```

结果：`Verified 15 complete Mio programs and 5 exercises: type checking and exact stdout. Hello build/exec/disasm passed.`

### 原生 AOT

`mochi-aot`：

```sh
mio build -o hello.mochi hello.mio
mochi-aot -o hello-go-native -target darwin-arm64 -heap-mib 1 hello.mochi
codesign --force --sign - hello-go-native
codesign --verify --strict hello-go-native
./hello-go-native
```

结果：生成 16384 字节的未签名 Mach-O，签名验证通过，运行输出 `Hello, Mio!`。`-heap-mib 0` 与 `1025` 均返回 `1`；`-target linux-arm64` 返回 `1`。

纯 Mio `native-aot`：

```sh
printf '%s' "$PWD/hello.mochi" > input.config
printf '%s' "$PWD/hello-pure-native" > output.config
"$MIO_HOME/native-aot" > native-build.log
grep '^native-aot: ok$' native-build.log
chmod +x hello-pure-native
codesign --force --sign - hello-pure-native
codesign --verify --strict hello-pure-native
./hello-pure-native
```

结果：日志为 `native-aot: ok` / `176` / `16384`，签名验证通过，运行输出 `Hello, Mio!`。截断 Mochi 输入时输出 `native-aot: decode failed`，进程退出码为 `0` 且不生成产物。

### LSP

启动 `mio lsp --stdio`，发送 `initialize`，读取响应后 `shutdown` / `exit`。结果：

- `serverInfo` 为 `{"name":"MioCore","version":"2.0.0"}`；
- capabilities 包含 completion、definition、documentSymbol、hover、references、signatureHelp、textDocumentSync；
- 退出码 `0`。

## 未覆盖范围

本轮**没有**重新执行：

- 完整 M18 Seed → Stage 1…5 多代链；
- 256 MiB GC 见证与 LLDB 观测；
- 全仓 Go 测试、AOT race、Native 自举固定点；
- Intel Mac、Linux、Windows 实机；
- VS Code Extension Host 或 JetBrains IDE 的 v2.0.0 端到端测试；
- Developer ID 签名、notarization 或互联网下载 Gatekeeper 首次安装体验。

上述项目的既有证据属于核心仓库与 RC4/CI 记录，保留原始来源和时间，不改标为本轮新执行。M18 的正式结论见 `docs/NATIVE_AOT_M18.md`，平台边界见 `docs/releases/v2.0.0-platforms.md`。
