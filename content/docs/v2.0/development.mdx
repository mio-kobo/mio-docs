## 已发布

Mio **v2.0.0** 已于 2026-10-21 正式发布：

- Tag：[`v2.0.0`](https://github.com/mio-kobo/mio/releases/tag/v2.0.0)
- 源码提交：`0ce04dd06c6c6e4e26f55a2c0b4ffb23aa942a0a`
- 平台：macOS Apple Silicon / ARM64
- CLI：`Mio 2.0.0`

v2.0.0 的核心成果是 M18 纯 Mio Mochi → Native AOT 自托管，以及 Mochi VM、Native AOT、精确 GC、LSP 和 Bunko 标准库的正式工具链。

## M18 结论

M18 的正式链为：

```text
Go 源码前端 → native-aot.mochi
Go AOT → Seed
Seed → Native Stage 1 → 2 → 3 → 4 → 5
```

- Stage 1–4 实际执行并生成下一代；
- Stage 1–5 未签名 Mach-O 完整字节一致；
- Stage 5 已生成、解析、签名和 strict verify，但未计为已执行代次；
- 正式链中 Go AOT 只生成 Seed，后续原生生成由纯 Mio 完成；
- 256 MiB 受限堆见证触发了真实 GC，输出仍与固定点一致。

**边界：** 这不表示从 `.mio` 源码开始的完整工具链已经摆脱 Go。源码前端、VM 和 LSP 仍为 Go 实现；从源码重建工具和首次 Seed 仍需要 Go。
