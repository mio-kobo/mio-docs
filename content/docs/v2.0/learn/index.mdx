## 如何使用示例

把每一课的完整代码分别保存为一个 `.mio` 文件，然后执行：

```sh
./mio check path/to/lesson.mio
./mio run path/to/lesson.mio
```

不要把多课程序同时粘贴到同一文件里。包级声明可能重名；每个示例应独立运行。

教程基于 Mio v2.0.0 正式版（Tag `v2.0.0`，提交 `0ce04dd06c6c6e4e26f55a2c0b4ffb23aa942a0a`）。示例已使用官方 `mio-2.0.0-darwin-arm64.tar.gz` 的 CLI 在 macOS 15.6.1 ARM64 上执行，15 个完整程序与 5 个练习通过类型检查并逐字节匹配 stdout。未在本轮重跑完整 M18、GC 见证或跨平台测试；这些边界见 [验证与来源](/docs/v2.0/tooling/verification)。
