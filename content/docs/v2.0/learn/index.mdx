欢迎来到 Mio V2.0 学习指南。

Mio 是一门使用日语罗马字关键字的静态强类型编程语言。本栏目从基础语法开始，逐步介绍程序控制、数据类型、集合、自定义类型和进阶特性，再学习如何组织包和使用 Bunko 标准库。

建议先阅读 [安装与运行](/docs/v2.0/getting-started)。如果只想快速体验，可以直接运行页面中带有 Playground 的完整 Mio 示例。

## 如何运行示例

学习页面中的可运行示例一般可以保存为独立的 `.mio` 文件，例如：

```mio title="Hello.mio"
chant("Hello, Mio!");
```

在本地终端执行：

```sh
mio check Hello.mio
mio run Hello.mio
```

如果代码块显示 **Playground**，还可以在网页中直接检查、编辑和运行。每个代码块都是独立程序，使用标准库时必须在代码块内部包含相应的 `yobu` 导入。

浏览器目前只嵌入 `kiso/math`、`kiso/array`、`kiso/string`、`kiso/bytes` 和 `kiso/utf8`。依赖其他包、多个源文件或特殊测试环境的示例，需要保存到本地并使用 CLI 执行。测试文件应通过 `mio test` 运行，而不是普通的 `mio run`。

如果遇到导入、类型或运行错误，可参阅 [故障排查](/docs/v2.0/tooling/troubleshooting)。
