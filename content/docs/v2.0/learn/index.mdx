欢迎来到 Mio V2.0 学习指南。

Mio 是一门使用日语罗马字关键字的静态强类型编程语言。本栏目将从基础语法开始，逐步介绍程序控制、数据结构、自定义类型和进阶特性，最后学习如何使用 Bunko 标准库和开发工具。

如果你还没有安装 Mio，建议先阅读 [安装与运行](/docs/v2.0/getting-started)。第一次学习可以按照下方顺序阅读；如果已经有编程基础，也可以直接选择感兴趣的章节。

## 如何运行示例

学习页面中的 Mio 示例通常可以作为独立的 `.mio` 文件运行。例如：

```mio title="Hello.mio"
chant("Hello, Mio!");
```

将代码保存为 `Hello.mio`，然后在终端执行：

```sh
mio check Hello.mio
mio run Hello.mio
```

如果页面提供 **Playground**，也可以直接在浏览器中检查、编辑和运行对应的完整程序。各个代码块独立执行，使用标准库时必须在代码块中写出相应的 `yobu` 导入语句。

网页 Playground 当前支持 `kiso/math`、`kiso/array`、`kiso/string`、`kiso/bytes` 和 `kiso/utf8`。文件系统、测试和其他未嵌入浏览器运行环境的模块，应使用本地 Mio CLI；测试程序请使用 `mio test`，而不是普通的 `mio run`。

所有章节以 Mio V2.0.0 已实现的语言特性为基础。需要查询更精确的语法规则时，可查阅 [语言参考](/docs/v2.0/reference)；如果遇到编译或运行问题，可以参考 [故障排查](/docs/v2.0/tooling/troubleshooting)。
