## 闭包与函数值

在 Mio 中，函数不仅可以通过名称直接调用，还可以作为值保存到变量中，并像其他数据一样传递给函数或从函数中返回。

能够保存、传递和调用的函数称为函数值（Function Value）。如果一个函数还使用了其外部词法作用域中的变量，就可以形成闭包（Closure）。

例如：

```mio title="Closure.mio"
kaku double = waza (value: int64) -> int64 {
    kaesu value * 2;
};

chant(double(21));
```

在上述示例中，`double` 保存的是一个匿名函数值。调用 `double(21)` 时，程序才会执行函数体。

### 函数类型

Mio 使用 `(参数类型) -> 返回类型` 表示函数类型。

例如：

```text
(int64) -> int64
(string, int64) -> bool
() -> unit
```

其中，`(int64) -> int64` 表示接收一个整数并返回整数的函数，`() -> unit` 表示没有参数、也不返回普通值的函数。

函数类型中的参数类型、参数数量和返回类型都属于静态类型检查的一部分。

### 将函数保存到变量

Mio 允许将普通具名函数作为函数值使用。

```mio title="Closure.mio"
waza twice(value: int64) -> int64 {
    kaesu value * 2;
}

kaku operation: (int64) -> int64 = twice;

chant(operation(21));
```

这里的 `operation` 是一个函数类型的变量。变量可以保存具有兼容函数签名的函数值。

需要注意，函数值本身不能通过 `==` 或 `!=` 运算符直接比较。

### 匿名函数

匿名函数（Anonymous Function）不需要独立的函数名称，可以直接出现在表达式中。

基本形式如下：

```text
waza (参数名: 类型) -> 返回类型 {
    // 函数体
}
```

例如：

```mio title="Closure.mio"
kaku add = waza (a: int64, b: int64) -> int64 {
    kaesu a + b;
};

chant(add(10, 20));
```

在上述示例中，匿名函数被保存到变量 `add` 中，随后通过 `add(10, 20)` 调用。

匿名函数本身是一个表达式，因此当它用于变量初始化时，声明语句末尾仍需使用分号。

### 函数作为参数

当一个函数接收其他函数作为参数时，这种用法通常称为高阶函数（Higher-Order Function）。

Mio 可以通过函数类型声明这样的参数。

```mio title="Closure.mio"
waza apply(value: int64, transform: (int64) -> int64) -> int64 {
    kaesu transform(value);
}

waza double(value: int64) -> int64 {
    kaesu value * 2;
}

chant(apply(21, double));
```

在上述示例中，`transform` 是函数参数，`apply` 会调用传入的函数来处理 `value`。

我们也可以直接传递匿名函数，而不需要提前为函数命名：

```mio title="Closure.mio"
waza apply(value: int64, transform: (int64) -> int64) -> int64 {
    kaesu transform(value);
}

chant(apply(10, waza (value: int64) -> int64 {
    kaesu value + 5;
}));
```

这种写法适合将某个操作作为参数传入通用的处理流程。

### 闭包捕获外部变量

当匿名函数访问其外部作用域中的局部变量时，就形成了闭包。

例如：

```mio title="Closure.mio"
waza make_counter() -> () -> int64 {
    kaku count = 0;

    kaesu waza () -> int64 {
        count = count + 1;
        kaesu count;
    };
}

kaku next = make_counter();

chant(next());
chant(next());
chant(next());
```

在上述示例中，`make_counter` 返回一个无参数、返回整数的函数值。

返回的匿名函数使用了外层的局部变量 `count`。即使 `make_counter()` 已经结束，闭包仍然能够保存并访问该变量的状态。

需要注意，闭包捕获的是变量的共享存储，而不是在创建函数时简单复制一个独立数值。

### 不同闭包的独立状态

每次调用创建局部变量的外层函数时，都可以得到一组新的捕获状态。

```mio title="Closure.mio"
waza make_counter() -> () -> int64 {
    kaku count = 0;

    kaesu waza () -> int64 {
        count = count + 1;
        kaesu count;
    };
}

kaku first = make_counter();
kaku second = make_counter();

chant(first());
chant(first());
chant(second());
```

这里的 `first` 与 `second` 是分别创建的两个闭包，每个闭包都有自己对应的 `count` 变量。

如果多个闭包是在同一次外层函数调用中创建的，并且捕获同一个可变局部变量，它们则会共享该变量的更新。

### 多个闭包共享捕获

Mio 允许多个闭包访问相同的外部变量。

```mio title="Closure.mio"
waza make_pair() -> [](() -> int64) {
    kaku value = 0;

    kaku increment = waza () -> int64 {
        value = value + 1;
        kaesu value;
    };

    kaku read = waza () -> int64 {
        kaesu value;
    };

    kaesu [increment, read];
}

kaku pair = make_pair();

chant(pair[0]());
chant(pair[1]());
chant(pair[0]());
```

在上述示例中，`increment` 和 `read` 捕获的是同一个变量 `value`。

因此，`increment` 修改变量后，`read` 也会观察到更新后的数值。

这个示例同时说明，Mio 支持使用 `[](() -> int64)` 表示保存函数值的数组。

### 递归闭包

Mio 支持显式声明函数类型的递归闭包。

```mio title="Closure.mio"
waza make_factorial() -> (int64) -> int64 {
    kaku factorial: (int64) -> int64 = waza (value: int64) -> int64 {
        moshi (value <= 1) {
            kaesu 1;
        }
        kaesu value * factorial(value - 1);
    };

    kaesu factorial;
}

kaku factorial = make_factorial();
chant(factorial(5));
```

由于递归闭包需要在初始化表达式内部引用自己，必须提供明确的函数类型，供编译器建立正确的类型和符号绑定。

### 函数值的限制

Mio V2.0 允许函数值保存在变量、数组和结构体字段中，也允许它们作为参数传递或从函数中返回。

不过，普通具名函数 `waza name(...)` 必须声明在文件顶层。需要在函数体内部创建函数时，应使用匿名 `waza (...) -> ... { ... }` 表达式。

此外，`unit` 表示函数没有普通返回值。`unit` 函数可以被调用，但不能把它的调用结果保存为一个普通变量。

对于可能被闭包修改的可空变量，调用闭包后，先前建立的非空判断不一定仍然有效。需要重新检查该变量是否为 `mu`。
