## 注释

`注释`（Comment）用于在源代码中添加说明，帮助开发者理解程序的功能与实现逻辑。

Mio 支持两种注释方式：`单行注释` 和 `块注释`。

注释仅用于解释代码，不会作为程序指令执行，也不会影响程序的运行结果。

### 单行注释
单行注释以 `//` 开始，从 `//` 到当前行末尾的内容都会被视为注释。

```mio title="Comment.mio"
// 声明一个整数变量
kaku number = 10;

// 输出变量的值
chant(number);
```

单行注释也可以写在代码后面：

```mio title="Comment.mio"
kaku age = 18; // 声明年龄变量

chant(age); // 输出年龄
```

单行注释适合解释变量、函数调用或某一行代码的用途。

### 多行注释
当需要编写较长的说明时，可以使用块注释。

块注释以 `/*` 开始，以 `*/` 结束，其间的内容都会被视为注释。

```mio title="Comment.mio"
/*
这是一个多行注释。

可以在这里说明程序的用途、
主要功能或需要注意的事项。
*/

kaku message = "Hello, Mio!";

chant(message);
```

块注释不受单行长度限制，适合为较复杂的代码添加说明。

### 为函数添加注释

在实际开发中，我们通常会在函数声明前添加注释，说明函数的用途、参数以及返回值。

例如：

```mio title="Comment.mio"
/*
计算两个整数的和。

参数：
  a - 第一个整数
  b - 第二个整数

返回值：
  两个整数相加后的结果。
*/
waza add(a: int64, b: int64) -> int64 {
    kaesu a + b;
}

// 调用 add 函数并输出结果
chant(add(10, 20));
```

通过这种方式，即使其他开发者没有阅读函数内部的实现，也能够通过注释了解该函数的基本用途。

这里使用的是普通块注释，并非具有特殊语义的文档注释语法。
