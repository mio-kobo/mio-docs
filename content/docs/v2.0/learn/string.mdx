## 字符串

字符串（String）用于表示和存储文本数据。

在 Mio 中，字符串使用 `string` 类型表示，并通过双引号 `"` 包围字符串内容。

Mio 使用 UTF-8 编码，因此字符串可以包含英文字母、数字、中文、日文以及其他 Unicode 字符。

例如：

```mio title="String.mio"
kaku name = "Mio";
kaku message = "Hello, 世界！";

chant(name);
chant(message);
```

在上述示例中，`name` 和 `message` 都是 `string` 类型的变量。

Mio 支持字符串比较、拼接、查找、UTF-8 编码转换等功能，其中部分操作通过标准库 `kiso/string` 实现。

### 字符串声明

Mio 使用 `kaku` 关键字声明字符串变量。

基本语法如下：

```text
kaku 变量名: string = "字符串内容";
```

例如：

```mio title="String.mio"
kaku name: string = "Mio";
kaku language: string = "Mio Language";
kaku empty: string = "";

chant(name);
chant(language);
chant(empty);
```

在上述示例中，`name` 和 `language` 被显式声明为 `string` 类型。

`empty` 则表示一个空字符串，其内容为空，但仍然是有效的字符串值。

如果没有显式指定类型，Mio 会根据字符串字面量自动推断变量类型。

例如：

```mio title="String.mio"
kaku message = "Hello, Mio!";
```

这里的 `message` 会被推断为 `string` 类型。

字符串变量可以重新赋值，但新的值仍然必须符合 `string` 类型。

```mio title="String.mio"
kaku message = "Hello";

message = "Hello, Mio!";

chant(message);
```

需要注意，字符串本身是不可变的。重新赋值是让变量保存另一个字符串值，而不是直接修改原字符串内部的字符。

### 字符串转义

在 Mio 中，字符串可以包含转义字符（Escape Sequence），用于表示换行、制表符等特殊字符。

转义字符通过反斜杠 `\` 开始。

Mio V2.0 支持以下字符串转义序列：

| 转义序列 | 说明 |
| --- | --- |
| `\n` | 换行 |
| `\r` | 回车 |
| `\t` | 水平制表符 |
| `\"` | 双引号 |
| `\\` | 反斜杠 |

例如：

```mio title="String.mio"
kaku message = "Hello\nMio!";

chant(message);
```

在上述示例中，`\n` 表示换行，因此输出内容会被分成两行。

如果需要在字符串中包含双引号，可以使用 `\"`：

```mio title="String.mio"
kaku message = "Mio says \"Hello!\"";

chant(message);
```

需要注意，Mio V2.0 不允许普通字符串字面量直接跨越多行。如果需要表示多行文本，应使用 `\n` 转义字符。

### 字符串比较

Mio 支持通过 `==` 和 `!=` 运算符比较两个字符串。

其中，`==` 用于判断两个字符串是否相等，`!=` 用于判断两个字符串是否不同。

例如：

```mio title="String.mio"
kaku a = "Mio";
kaku b = "Mio";
kaku c = "Hello";

chant(a == b);
chant(a != c);
chant(a == c);
```

在上述示例中，`a` 和 `b` 的字符串内容相同，因此 `a == b` 返回 `hai`。

而 `a` 和 `c` 的内容不同，因此 `a == c` 返回 `iie`。

字符串比较也可以用于条件判断：

```mio title="String.mio"
kaku language = "Mio";

moshi (language == "Mio") {
    chant("当前使用 Mio 语言");
} sore {
    chant("其他语言");
}
```

需要注意，Mio 的字符串比较区分大小写，`"Mio"` 和 `"mio"` 不会被视为相同的字符串。

目前 Mio 不支持直接使用 `<`、`>`、`<=` 或 `>=` 比较字符串大小。

### 字符串拼接

字符串拼接（Concatenation）用于将多个字符串组合成一个新的字符串。

Mio V2.0 不支持直接使用 `+` 运算符连接字符串，而是通过 `kiso/string` 标准库提供的 `concat()` 函数实现。

使用前需要通过 `yobu` 导入字符串包。

例如：

```mio title="String.mio"
yobu "kiso/string";

kaku first = "Hello, ";
kaku second = "Mio!";

kaku result = string.concat(first, second);

chant(result);
```

在上述示例中，`yobu "kiso/string";` 用于导入 Mio 的字符串标准库。

`string.concat(first, second)` 将两个字符串组合，并返回一个新的字符串。

原来的 `first` 和 `second` 不会被修改。

需要注意，`string.concat()` 每次都会创建新的字符串。如果需要连续拼接大量文本，可以使用标准库提供的 `StringBuilder`。

### 字符串长度

Mio 使用 UTF-8 编码保存字符串，因此需要区分**字节长度**和**Unicode 字符数量**。

一个英文 ASCII 字符通常占用一个字节，而中文、日文和部分特殊字符可能占用多个字节。

Mio 的 `kiso/string` 标准库提供两个相关函数：

| 函数 | 说明 |
| --- | --- |
| `string.byte_len()` | 获取字符串的 UTF-8 字节长度 |
| `string.rune_count()` | 获取字符串包含的 Unicode 标量值数量 |

例如：

```mio title="String.mio"
yobu "kiso/string";

kaku message = "澪Mio";

chant(string.byte_len(message));
chant(string.rune_count(message));
```

在上述示例中，`澪` 占用三个 UTF-8 字节，而 `Mio` 包含三个 ASCII 字符，各占一个字节。

因此，整个字符串共占用 `6` 个字节，但包含 `4` 个 Unicode 标量值。

需要注意，`string.rune_count()` 计算的是 Unicode 标量值数量，并不一定等于用户视觉上看到的字符数量。例如，组合音符和某些 Emoji 可能由多个 Unicode 标量值组成。

此外，Mio 的内置 `len()` 用于数组长度，不能直接通过 `len(message)` 获取字符串长度。

### 字符串查找

Mio 通过 `kiso/string` 标准库提供字符串查找功能。

常用函数包括：

| 函数 | 说明 |
| --- | --- |
| `string.contains()` | 判断是否包含指定字符串 |
| `string.has_prefix()` | 判断是否以指定字符串开头 |
| `string.has_suffix()` | 判断是否以指定字符串结尾 |
| `string.index()` | 查找指定字符串首次出现的位置 |

例如：

```mio title="String.mio"
yobu "kiso/string";

kaku message = "Hello, Mio!";

chant(string.contains(message, "Mio"));
chant(string.has_prefix(message, "Hello"));
chant(string.has_suffix(message, "Mio!"));
chant(string.index(message, "Mio"));
```

在上述示例中，`contains()` 用于判断字符串中是否包含指定内容。

`has_prefix()` 和 `has_suffix()` 则分别用于检查字符串的开头与结尾。

`index()` 返回指定内容首次出现的位置，如果没有找到，则返回 `-1`。

需要注意，`string.index()` 返回的是 **UTF-8 字节偏移量**，而不是 Unicode 字符的位置。

例如：

```mio title="String.mio"
yobu "kiso/string";

kaku message = "你Mio";

chant(string.index(message, "Mio"));
```

由于汉字 `你` 占用三个 UTF-8 字节，因此后面的 `"Mio"` 从字节偏移量 `3` 开始。

这也是在处理多语言文本时需要特别注意的地方。

### 字符串与字节数组

Mio 可以通过 `kiso/string` 标准库将字符串转换为 UTF-8 字节数组。

其中，`string.to_bytes()` 用于将字符串转换为 `[]uint8` 类型的字节数组。

例如：

```mio title="String.mio"
yobu "kiso/string";

kaku message = "Mio";

kaku data = string.to_bytes(message);

chant(len(data));
chant(data[0]);
```

在上述示例中，`string.to_bytes(message)` 将字符串转换为字节数组。

`M` 对应的 UTF-8 字节值为 `77`，因此 `data[0]` 输出 `77`。

转换得到的数组具有独立的存储空间，因此修改字节数组不会影响原来的字符串。

我们也可以通过 `string.from_utf8()` 将字节数组转换回字符串。

例如：

```mio title="String.mio"
yobu "kiso/string";

kaku data: []uint8 = [77, 105, 111];

kaku message = string.from_utf8(data);

moshi (message != mu) {
    chant(message);
}
```

需要注意，`string.from_utf8()` 的返回类型是 `string?`。

如果输入的字节数组不是合法的 UTF-8 编码，函数会返回 `mu`。

因此，在使用转换结果前，通常需要检查它是否为空值。

### StringBuilder

当程序需要连续拼接多个字符串时，可以使用 `kiso/string` 提供的 `StringBuilder`。

`StringBuilder` 用于逐步构建字符串，避免每次追加文本都创建一个完整的新字符串。

例如：

```mio title="String.mio"
yobu "kiso/string";

kaku builder = string.new_builder();

string.write_string(builder, "Hello");
string.write_string(builder, ", ");
string.write_string(builder, "Mio!");

kaku result = string.builder_string(builder);

chant(result);
```

在上述示例中，`string.new_builder()` 创建一个空的字符串构造器。

`string.write_string()` 用于向构造器追加字符串，`string.builder_string()` 则用于获取最终构建的字符串。

Mio 还支持向 `StringBuilder` 追加单个 Unicode 字符。

例如：

```mio title="String.mio"
yobu "kiso/string";

kaku builder = string.new_builder();

string.write_string(builder, "Mio");
string.write_rune(builder, '!');

chant(string.builder_string(builder));
```

其中，`string.write_rune()` 接收一个 `rune` 类型的值，将其编码为 UTF-8 后追加到构造器中。

`StringBuilder` 还提供 `builder_len()`、`builder_capacity()` 和 `builder_reset()` 等函数，用于查询字节长度、容量和清空当前内容。

需要注意，`StringBuilder` 内部使用共享的可变字节缓冲区，因此将构造器赋值给另一个变量时，不会自动创建独立的缓冲区。

而 `string.builder_string()` 返回的是独立的不可变字符串副本，之后修改构造器不会改变已经生成的字符串。

### 可空字符串

Mio 支持可空字符串类型 `string?`，用于表示一个字符串可能尚未被设置。

例如：

```mio title="String.mio"
kaku message: string? = mu;

moshi (message == mu) {
    chant("字符串尚未设置");
}

message = "Hello, Mio!";

moshi (message != mu) {
    chant(message);
}
```

在上述示例中，`string?` 表示变量既可以保存有效字符串，也可以保存空值 `mu`。

需要注意，空字符串 `""` 和 `mu` 并不相同。

空字符串是一个有效的 `string` 值，只是它不包含任何文本内容；而 `mu` 表示没有值。

### 字符串的注意事项

在 Mio V2.0 中，使用字符串时需要注意以下规则：

- 字符串使用双引号 `"` 包围，采用 UTF-8 编码。
- 普通字符串字面量不能直接跨越多行。
- 字符串本身不可变，不能直接修改某个字符。
- 字符串支持 `==` 和 `!=` 比较，但不支持通过 `+` 运算符拼接。
- 字符串拼接、查找和长度查询主要通过 `kiso/string` 实现。
- UTF-8 字节长度与 Unicode 标量值数量可能不同。
- `string.index()` 返回字节偏移量，而不是字符索引。
- 目前不支持直接对字符串进行索引赋值或使用切片语法截取字符串。
- `string.from_utf8()` 可能返回 `mu`，使用结果时需要处理可空类型。

此外，`kiso/string` 的操作主要针对 UTF-8 字节与 Unicode 标量值，不提供 Unicode 规范化、自动大小写折叠或字素簇分割等功能。
