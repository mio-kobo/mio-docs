## 运算符

运算符（Operator）是程序中用于执行计算、比较和逻辑判断的特殊符号。

在 Mio 中，我们可以通过运算符对变量和数据进行处理，例如计算两个数字的和、比较数值大小，或组合多个条件表达式。

```mio title="Operator.mio"
kaku a = 10;
kaku b = 20;

chant(a + b);
chant(a < b);
```

Mio V2.0 提供算术运算符、比较运算符、逻辑运算符以及赋值运算符。

### 算术运算符

算术运算符用于对数值进行数学计算。

Mio 支持以下算术运算符：

| 运算符 | 名称   | 说明        |
|-----|------|-----------|
| `+` | 加法   | 计算两个数值的和  |
| `-` | 减法   | 计算两个数值的差  |
| `*` | 乘法   | 计算两个数值的乘积 |
| `/` | 除法   | 计算两个数值的商  |
| `-` | 一元负号 | 将数值取负     |

例如：
```mio title="Operator.mio"
kaku a = 10;
kaku b = 3;

chant(a + b);
chant(a - b);
chant(a * b);
chant(a / b);
chant(-a);
```

需要注意，当两个操作数都是整数时，除法运算会执行整数除法，小数部分将被舍弃，结果向零截断。

例如：

```mio title="Operator.mio"
chant(7 / 2);
chant(-7 / 2);
```
如果需要保留小数部分，可以使用浮点数类型：

```mio title="Operator.mio"
kaku a: float64 = 7.0;
kaku b: float64 = 2.0;
```
Mio 是静态强类型语言，数值运算通常要求两侧操作数具有相同的数值类型，不会自动将一个已经确定类型的整数变量转换为浮点变量。数值字面量则可以根据明确的类型上下文进行检查。

### 比较运算符

比较运算符用于比较两个值，并返回一个布尔值（bool）。

Mio 使用 `hai` 表示真，使用 `iie` 表示假。

| 运算符  | 名称   | 说明              |
|------|------|-----------------|
| `==` | 等于   | 判断两个值是否相等       |
| `!=` | 不等于  | 判断两个值是否不同       |
| `>`  | 大于   | 判断左侧数值是否大于右侧    |
| `<`  | 小于   | 判断左侧数值是否小于右侧    |
| `>=` | 大于等于 | 判断左侧数值是否大于或等于右侧 |
| `<=` | 小于等于 | 判断左侧数值是否小于或等于右侧 |

例如：

```mio title="Operator.mio"
kaku a = 10;
kaku b = 20;

chant(a == b);
chant(a != b);
chant(a > b);
chant(a < b);
chant(a >= b);
chant(a <= b);
```

比较运算符也可以用于条件判断：

```mio title="Operator.mio"
kaku age = 18;

moshi (age >= 18) {
    chant("已成年");
} sore {
    chant("未成年");
}
```

其中，== 和 != 还可以用于比较相同类型的字符串、布尔值等受支持的数据类型。

```mio title="Operator.mio"
chant("Mio" == "Mio");
chant("Mio" != "Hello");
```
需要注意，`<`、`>`、`<=` 和 `>=` 用于数值比较，不能直接用于比较字符串的字典顺序。

### 逻辑运算符

逻辑运算符用于处理布尔表达式，常用于组合多个条件。

Mio 支持以下逻辑运算符：

| 运算符    | 名称  | 说明                |
|--------|-----|-------------------|
| `&&`   | 逻辑与 | 两个条件都为真时返回 `hai`  |
| `\|\|` | 逻辑或 | 任意一个条件为真时返回 `hai` |
| `!`    | 逻辑非 | 将布尔值取反            |

例如：

```mio title="Operator.mio"
chant(hai && hai);
chant(hai && iie);
chant(hai || iie);
chant(iie || iie);
chant(!hai);
chant(!iie);
```

逻辑运算符可以组合成较复杂的条件表达式：

```mio title="Operator.mio"
kaku age = 20;
kaku has_ticket = hai;

moshi (age >= 18 && has_ticket) {
    chant("允许进入");
} sore {
    chant("禁止进入");
}
```
### 短路求值

Mio 的 `&&` 和 `||` 支持短路求值（Short-circuit Evaluation）。

对于 `&&`，如果左侧表达式已经为 `iie`，则不会继续执行右侧表达式。

对于 `||`，如果左侧表达式已经为 `hai`，同样不会执行右侧表达式。

```mio title="Operator.mio"
waza check() -> bool {
    chant("执行检查");
    kaesu hai;
}

chant(iie && check());
chant(hai || check());
```

由于两个表达式都已经能够通过左侧条件确定最终结果，因此 `check()` 不会被调用。

短路求值不仅可以避免不必要的计算，也可以在条件判断中减少某些不安全的操作。

### 赋值运算符

赋值运算符用于将一个值保存到变量中。

Mio 使用 `=` 表示赋值。

```mio title="Operator.mio"
kaku number = 10;

number = 20;

chant(number);
```

其中，`kaku number = 10;` 用于声明并初始化变量，而 `number = 20;` 则用于修改已经声明的变量值。

赋值时，右侧表达式的类型必须与变量的类型兼容。

如果希望将变量的值增加，可以这样编写：

```mio title="Operator.mio"
kaku count = 0;

count = count + 1;

chant(count);
```

此外，赋值在 Mio 中属于语句，不是可以嵌套在其他表达式中的赋值表达式。

### 运算符优先级

当一个表达式中包含多个运算符时，Mio 会根据运算符的优先级决定计算顺序。

例如：

```mio title="Operator.mio"
chant(2 + 3 * 4);
```

因为乘法 `*` 的优先级高于加法 `+`，所以程序会先计算 `3 * 4`，再加上 `2`。

如果希望优先执行加法，可以使用括号 `()`：

```mio title="Operator.mio"
chant((2 + 3) * 4);
```

Mio V2.0 表达式的优先级从高到低如下：

| 优先级    | 运算符或表达式           | 说明       |
|--------|-------------------|----------|
| 1（最高）  | `.`               | 成员访问     |
| 2      | `[]`              | 索引访问     |
| 3      | `()`              | 函数调用     |
| 4      | `-`、`!`           | 一元负号、逻辑非 |
| 5      | `*`、`/`           | 乘法、除法    |
| 6      | `+`、`-`           | 加法、减法    |
| 7      | `<`、`<=`、`>`、`>=` | 大小比较     |
| 8      | `==`、`!=`         | 相等比较     |
| 9      | `&&`              | 逻辑与      |
| 10（最低） | `\|\|`            | 逻辑或      |

这里的 `.`、`[]`、`()` 分别表示成员访问、索引访问和函数调用等后缀表达式形式。

对于同一优先级的二元运算符，Mio 通常按照从左到右的顺序进行结合。

例如：

```mio title="Operator.mio"
chant(20 / 2 * 2);
chant(10 - 3 - 2);
```

为了避免复杂表达式产生歧义，建议在必要时使用括号明确运算顺序。

另外，`+` 目前只用于数值加法，不能直接用于字符串拼接。需要组合字符串时，应使用 Mio 标准库提供的字符串操作函数。
