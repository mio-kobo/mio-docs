## 标识符

标识符（Identifier）是程序中用于命名变量、函数、常量、结构体等程序元素的名称。

在 Mio 中，我们可以通过标识符引用已经声明的程序元素，使代码更容易阅读和维护。


```mio title="Identifier.mio"
kaku age = 18;

waza greet(name: string) -> unit {
    chant(name);
}

greet("Mio");
chant(age);
```

在上述代码中，age 是变量的标识符，greet 是函数的标识符，而 name 是函数参数的标识符。

### 标识符的命名规则

Mio 对标识符的命名有以下要求：

- 标识符只能由英文字母`a-z、A-Z`、`0-9`和下划线`_`组成。

- 标识符必须以`英文字母`或`下划线`开头，不能以`数字`开头。

- 标识符`区分大小写`，例如 `name` 和 `Name` 是两个不同的名称。

- 标识符不能使用 Mio 的保留关键字。

- 标识符不能包含`空格`或`其他特殊字符`。

以下是一些合法的标识符：

```
kaku name = "Mio";
kaku user_age = 18;
kaku count2 = 100;
kaku _value = 10;
kaku HelloWorld = "Hello!";
```

下面的写法则不符合 Mio 的标识符命名规则：

```
2count       // 不能以数字开头
user-name    // 不能包含连字符
user name    // 不能包含空格
user@name    // 不能包含特殊符号
用户名称      // 目前不支持中文标识符
```

需要注意，Mio 源代码支持 `UTF-8`，因此可以在字符串和注释中使用`中文`、`日文`及其他 `Unicode` 字符，但标识符目前仅支持上述 ASCII 字符。

### 标识符区分大小写

Mio 是一门区分大小写的编程语言。

这意味着，即使两个标识符使用相同的字母，只要大小写不同，它们就会被视为不同的名称。

例如：

```mio title="Identifier.mio"
kaku name = "Mio";
kaku Name = "Hello";
kaku NAME = "World";

chant(name);
chant(Name);
chant(NAME);
```

在这个示例中，name、Name 和 NAME 分别代表三个不同的变量。

因此，在使用标识符时，应当保持名称的大小写一致，避免因为拼写差异而产生错误。

### 关键字与标识符

Mio 中的关键字具有特定的语法含义，不能直接作为标识符使用。

例如，`kaku` 用于声明变量，`waza` 用于声明函数，`moshi` 用于条件判断。

```
kaku kaku = 10;
kaku moshi = 20;
waza waza() -> unit {}
```

由于 kaku、moshi 和 waza 是语言关键字，编译器不会将它们识别为普通标识符。

`Mio V2.0` 的保留关键字包括：

| 关键字       | 中文含义 | 用途说明         |
|-----------|------|--------------|
| `kaku`    | 变量声明 | 声明变量         |
| `teisu`   | 常量声明 | 声明编译期常量      |
| `waza`    | 函数   | 声明函数         |
| `kaesu`   | 返回   | 从函数中返回结果     |
| `moshi`   | 如果   | 条件判断         |
| `sore`    | 否则   | 条件不成立时执行其他分支 |
| `aida`    | 循环   | 根据条件重复执行代码   |
| `nukeru`  | 跳出   | 退出当前循环       |
| `tsuzuku` | 继续   | 跳过当前循环的剩余部分  |
| `hai`     | 真    | 布尔值 `true`   |
| `iie`     | 假    | 布尔值 `false`  |
| `mu`      | 空值   | 表示空值         |
| `kata`    | 结构体  | 声明结构体类型      |
| `sentaku` | 枚举   | 声明枚举类型       |
| `awase`   | 匹配   | 对枚举值进行模式匹配   |
| `baai`    | 分支   | 定义模式匹配的分支    |
| `yobu`    | 导入   | 导入其他包        |
| `koukai`  | 公开   | 导出包中的公开声明    |

另外，`chant`、`len` 等是 Mio 提供的内置函数，`int64`、`string` 等是类型名称，它们并不属于语言关键字，但不建议使用这些名称来命名自己的变量或函数，以免造成混淆。
