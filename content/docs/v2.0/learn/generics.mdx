## 泛型

泛型（Generics）允许我们在定义函数或自定义类型时使用类型参数，从而让同一份代码适用于多种数据类型。

在 Mio 中，泛型可以用于函数、结构体和枚举。编译器会在使用这些声明时确定具体类型，并进行静态类型检查。

例如：

```mio title="Generic.mio"
waza identity<T>(value: T) -> T {
    kaesu value;
}

chant(identity(42));
chant(identity("Mio"));
```

在上述示例中，`T` 是一个类型参数。`identity` 可以接收并返回同一种类型的值，而不需要为整数和字符串分别编写函数。

### 声明泛型函数

Mio 使用 `<T>` 在函数名称之后声明类型参数。

基本形式如下：

```text
waza 函数名<T>(参数名: T) -> T {
    // 函数体
}
```

例如：

```mio title="Generic.mio"
waza first<T>(values: []T) -> T? {
    moshi (len(values) == 0) {
        kaesu mu;
    }

    kaesu values[0];
}

kaku number = first([10, 20, 30]);

moshi (number != mu) {
    chant(number);
}
```

这里的 `first` 可以接收不同元素类型的数组。由于数组可能为空，返回类型使用 `T?`，表示结果也可能是 `mu`。

需要注意，类型参数本身并不允许任意操作。对于没有数值约束的 `T`，不能直接假定其支持加法、乘法等算术运算。

### 类型参数推断

调用泛型函数时，如果编译器能从参数推断出类型，就不需要显式写出类型参数。

例如：

```mio title="Generic.mio"
waza echo<T>(value: T) -> T {
    kaesu value;
}

kaku number = echo(100);
kaku message = echo("Hello");

chant(number);
chant(message);
```

在上述示例中，`echo(100)` 的 `T` 被推断为 `int64`，而 `echo("Hello")` 的 `T` 被推断为 `string`。

如果类型无法从实参或目标上下文确定，就需要显式指定类型参数。

### 显式指定类型参数

Mio 的泛型函数声明使用尖括号 `<T>`，调用时显式指定类型参数则使用方括号 `[T]`。

例如：

```mio title="Generic.mio"
waza first<T>(values: []T) -> T? {
    moshi (len(values) == 0) {
        kaesu mu;
    }
    kaesu values[0];
}

kaku item = first[int64]([7, 8]);
kaku empty = first[int64]([]);

moshi (item != mu) {
    chant(item);
}

chant(empty == mu);
```

在上述示例中，`first[int64]` 表示本次调用使用 `int64` 作为类型参数。

对于空数组 `[]`，显式指定类型参数尤其有用，因为编译器无法直接从空数组内容推断元素类型。

### 多个类型参数

Mio 的泛型函数可以同时声明多个类型参数，使用逗号分隔。

例如：

```mio title="Generic.mio"
waza apply<T, U>(value: T, transform: (T) -> U) -> U {
    kaesu transform(value);
}

kaku result = apply(21, waza (value: int64) -> int64 {
    kaesu value * 2;
});

chant(result);
```

这里的 `T` 表示输入类型，`U` 表示返回类型。

通过多个类型参数，泛型函数可以在保留静态类型检查的同时连接不同类型的数据。

### 泛型结构体

Mio 允许在结构体声明中使用类型参数。

```mio title="Generic.mio"
kata Box<T> {
    value: T;
}

kaku number = Box[int64] { value: 42 };
kaku message = Box[string] { value: "Mio" };

chant(number.value);
chant(message.value);
```

其中，`Box<T>` 是一个泛型结构体定义。

构造时可以通过 `Box[int64]` 或 `Box[string]` 显式指定字段的具体类型。在具有明确上下文时，编译器也能从初始化字段推断类型参数。

需要注意，类型标注使用尖括号，例如 `Box<int64>`；构造表达式显式使用类型参数时，则使用方括号，例如 `Box[int64] { ... }`。

### 泛型枚举

枚举也可以通过类型参数让不同的变体保存不同类型的数据。

```mio title="Generic.mio"
sentaku Result<T, E> {
    Ok(T);
    Err(E);
}

kaku result: Result<int64, string> = Result.Ok(42);

awase (result) {
    baai Ok(value) {
        chant(value);
    }
    baai Err(message) {
        chant(message);
    }
}
```

这里的 `T` 表示成功时保存的值类型，`E` 表示失败时保存的数据类型。

通过泛型枚举，可以在不同调用场景中复用相同的结果结构。

### 泛型与数组

数组类型 `[]T` 可以直接包含泛型类型参数，因此常用于编写可复用的数组处理函数。

```mio title="Generic.mio"
waza count<T>(values: []T) -> int64 {
    kaesu len(values);
}

chant(count([1, 2, 3]));
chant(count(["A", "B"]));
```

`count` 不需要知道元素的具体类型，只需要数组支持 `len()` 操作。

对于依赖算术运算的泛型函数，则需要使用 Mio 已支持的泛型约束，例如 `T: Number`。泛型约束的具体规则可以在「泛型约束」章节中进一步了解。

### 泛型的类型限制

泛型不会绕过 Mio 的静态类型系统。同一个类型参数在一次调用中必须保持一致，参数和返回值需要符合函数声明的类型关系。

例如，下面的函数要求两个参数具有相同类型：

```mio title="Generic.mio"
waza choose<T>(first: T, second: T) -> T {
    kaesu first;
}

chant(choose(10, 20));
```

如果将已经确定为不同类型的变量同时传入，不会自动因为它们都属于数值类型而执行隐式类型转换。

Mio V2.0 目前没有用户自定义 Trait 约束、高阶类型（Higher-Kinded Types）或型变（Variance）语法，不应将其他语言的泛型功能直接套用到 Mio 中。
