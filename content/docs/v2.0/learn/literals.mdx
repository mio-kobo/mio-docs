## 字面量

字面量（Literal）是直接写在源代码中，用于表示固定值的表达式。

在 Mio 中，我们可以通过字面量表示整数、浮点数、字符串、布尔值以及空值等数据，而不必事先声明变量。

例如：

```mio title="Literal.mio"
kaku age = 18;
kaku name = "Mio";
kaku enabled = hai;

chant(age);
chant(name);
chant(enabled);
```

在上述示例中，`18` 是整数字面量，`"Mio"` 是字符串字面量，`hai` 是布尔字面量。

Mio V2.0 支持以下字面量：

| 字面量类型 | 示例 | 说明 |
| --- | --- | --- |
| 整数字面量 | `42` | 表示整数 |
| 浮点数字面量 | `3.14`、`1e3` | 表示浮点数 |
| 字符串字面量 | `"Hello, Mio!"` | 表示字符串 |
| 字符字面量 | `'A'` | 表示 Unicode 字符 |
| 布尔字面量 | `hai`、`iie` | 表示真或假 |
| 空值字面量 | `mu` | 表示空值 |
| 数组字面量 | `[1, 2, 3]` | 表示数组 |

### 整数字面量

整数字面量用于表示整数，由十进制数字组成。

例如：

```mio title="Literal.mio"
kaku a = 10;
kaku b = 100;
kaku c = 0;

chant(a);
chant(b);
chant(c);
```

默认情况下，Mio 会将没有明确类型上下文的整数字面量推断为 `int64` 类型。

如果需要使用其他整数类型，可以在变量声明时指定类型：

```mio title="Literal.mio"
kaku small: int8 = 100;
kaku count: uint32 = 1000;
kaku total: int64 = 5000;
```

其中，`int8`、`int64` 为有符号整数类型，`uint32` 为无符号整数类型。

整数字面量必须符合指定类型所允许的数值范围，否则编译器会报告错误。

需要注意，Mio V2.0 的整数字面量仅支持十进制形式，除 `0` 本身外，不允许以 `0` 开头，例如 `012`、`001` 都是不合法的写法。

此外，负数通过一元负号 `-` 与整数字面量组合形成，例如 `-10`。

### 浮点数字面量

浮点数字面量用于表示带有小数部分或使用科学计数法的数值。

例如：

```mio title="Literal.mio"
kaku pi = 3.14;
kaku price = 19.99;
kaku value = 0.5;

chant(pi);
chant(price);
chant(value);
```

默认情况下，Mio 会将没有明确类型上下文的浮点数字面量推断为 `float64` 类型。

Mio 还支持使用科学计数法表示浮点数，通过 `e` 或 `E` 指定以 10 为底的指数。

例如：

```mio title="Literal.mio"
chant(1e3);
chant(2.5e1);
chant(2.5e-1);
```

运行结果：

```text
1000
25
0.25
```

如果需要使用 `float32` 类型，可以显式指定变量类型：

```mio title="Literal.mio"
kaku rate: float32 = 0.5;
kaku pi: float32 = 3.14;
```

Mio 中的 `float32` 和 `float64` 分别采用 IEEE 754 单精度与双精度浮点数表示。

需要注意，浮点数无法精确表示所有十进制小数，因此某些运算可能存在精度误差。

### 字符串字面量

字符串字面量用于表示文本内容，使用双引号 `"` 包围。

Mio 的字符串采用 UTF-8 编码，因此可以直接包含中文、日文以及其他 Unicode 字符。

例如：

```mio title="Literal.mio"
kaku name = "Mio";
kaku message = "Hello, 世界！";

chant(name);
chant(message);
```

运行结果：

```text
Mio
Hello, 世界！
```

Mio 的字符串还支持转义字符（Escape Sequence），用于表示换行、制表符等特殊字符。

| 转义字符 | 说明 |
| --- | --- |
| `\n` | 换行符 |
| `\r` | 回车符 |
| `\t` | 水平制表符 |
| `\"` | 双引号 |
| `\\` | 反斜杠 |

例如：

```mio title="Literal.mio"
kaku message = "Hello\nMio!";

chant(message);
```

运行结果：

```text
Hello
Mio!
```

在上述示例中，`\n` 表示换行，因此字符串内容会被输出为两行。

需要注意，Mio V2.0 不允许普通字符串字面量直接跨越多行。如果需要在字符串中表示换行，应使用 `\n` 转义字符。

### 字符字面量

字符字面量使用单引号 `'` 包围，用于表示一个 Unicode 标量值。

Mio 使用 `rune` 类型表示字符，`rune` 是 `int32` 的类型别名。

例如：

```mio title="Literal.mio"
kaku letter = 'A';
kaku symbol = '中';

chant(letter);
chant(symbol);
```

运行结果：

```text
65
20013
```

这是因为 Mio 中的 `rune` 按照整数值进行处理，输出时会显示字符对应的 Unicode 码点数值。

字符字面量与字符串字面量并不相同。

例如：

```mio title="Literal.mio"
kaku character = 'A';
kaku text = "A";
```

其中，`character` 是 `rune` 类型，而 `text` 是 `string` 类型。

字符字面量必须包含且只能包含一个 Unicode 标量值。

Mio 同样支持字符转义，例如 `'\n'`、`'\t'`、`'\x41'`、`'\u4E2D'` 等形式。

### 布尔字面量

布尔字面量（Boolean Literal）用于表示逻辑上的真或假。

Mio 使用 `hai` 表示真，使用 `iie` 表示假，二者均属于 `bool` 类型。

例如：

```mio title="Literal.mio"
kaku enabled = hai;
kaku finished = iie;

chant(enabled);
chant(finished);
```

运行结果：

```text
hai
iie
```

布尔字面量通常用于条件判断与逻辑运算。

例如：

```mio title="Literal.mio"
kaku is_ready = hai;

moshi (is_ready) {
    chant("准备完成");
} sore {
    chant("尚未准备");
}
```

在上述示例中，`is_ready` 的值为 `hai`，因此程序会执行第一个条件分支。

### 空值字面量

Mio 使用 `mu` 表示空值（Nil），用于表示一个值不存在或尚未被提供的情况。

Mio 通过可空类型（Nullable Type）来表示允许包含空值的数据类型。

可空类型使用 `?` 标记。

例如：

```mio title="Literal.mio"
kaku score: int64? = mu;

moshi (score == mu) {
    chant("尚未设置分数");
}
```

在上述示例中，`int64?` 表示 `score` 既可以保存一个 `int64` 整数，也可以保存空值 `mu`。

需要注意，Mio 无法仅通过 `mu` 推断变量的具体类型。

因此，以下写法是不合法的：

```text
kaku value = mu;
```

正确的写法需要提供明确的可空类型：

```mio title="Literal.mio"
kaku value: int64? = mu;
```

此外，`mu` 与 `unit` 并不相同。`mu` 表示空值，而 `unit` 用于表示函数没有普通返回值。

### 数组字面量

数组字面量用于创建包含多个元素的数组，使用方括号 `[]` 包围。

例如：

```mio title="Literal.mio"
kaku numbers = [10, 20, 30];

chant(numbers[0]);
chant(numbers[1]);
chant(numbers[2]);
```

运行结果：

```text
10
20
30
```

数组中的元素通过索引访问，索引从 `0` 开始。

在 Mio 中，数组中的元素必须符合统一的元素类型。

例如：

```mio title="Literal.mio"
kaku numbers = [1, 2, 3];
kaku names = ["Mio", "Hello", "World"];
kaku flags = [hai, iie, hai];
```

其中，`numbers` 是整数数组，`names` 是字符串数组，`flags` 是布尔值数组。

Mio 也允许创建空数组，但由于空数组没有元素，编译器无法直接推断它的元素类型，因此需要提供明确的类型上下文。

例如：

```mio title="Literal.mio"
kaku numbers: []int64 = [];

chant(len(numbers));
```

运行结果：

```text
0
```

这里的 `[]int64` 表示一个元素类型为 `int64` 的数组。

### 结构体构造表达式

除了上述字面量，Mio 还支持通过结构体构造表达式创建自定义类型的值。

例如：

```mio title="Literal.mio"
kata Point {
    x: int64;
    y: int64;
}

kaku point = Point {
    x: 10,
    y: 20
};

chant(point.x);
chant(point.y);
```

运行结果：

```text
10
20
```

在上述示例中，`kata` 用于声明结构体类型，而 `Point { x: 10, y: 20 }` 用于创建一个 `Point` 类型的值。

结构体的字段可以通过 `.` 运算符访问。

结构体构造表达式与普通基础字面量有所不同，其具体语法将在结构体章节中进一步介绍。
