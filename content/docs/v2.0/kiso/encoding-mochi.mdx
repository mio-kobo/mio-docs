## Mochi 格式编码

Mochi 格式库用于解码、验证和规范化 Mio 虚拟机使用的 Mochi 字节码文件。它主要面向编译器、调试工具与格式检查工具的开发。

本库接受 `[]uint8` 字节，返回结构化的解码结果及错误信息；普通业务程序不必直接操作 Mochi 的内部格式。

本页以 Mio `v2.0.0` 已实现的公开接口为准，不包含未实现的函数或语言语法。

### 导入包

> **运行环境：** 当前网页 Playground 的 WASM 不包含此包。以下代码示例使用 Mio V2.0.0 CLI 与完整 Bunko 标准库，网页中仅展示代码，不提供无法运行的「运行」按钮。

通过 `yobu "kiso/encoding/mochi";` 导入本包，随后使用 `mochi.函数名(...)` 调用。

```mio title="Stdlib.mio"
yobu "kiso/encoding/mochi";
```

### 解码字节码

`decode` 校验输入后返回 `DecodeResult`。成功时 `value` 包含解码的 `File`，失败时 `error` 提供错误类型和位置；调用者要先检查错误再访问有效结果。

```mio title="Mochi.mio" no-run
yobu "kiso/encoding/mochi";

kaku input: []uint8 = [];
kaku result = mochi.decode(input);
chant(result.error != mu);
```

### 规范化与摘要

`canonical_bytes` 将有效的已解码文件规范化重编码；`summarize` 给出版本、常量、函数和指令规模等统计信息。两者都面向有效的 `mochi.File`。

### 文件读取

`decode_file` 可以从文件路径读取并校验字节码，读文件失败与格式错误都会以结果错误表示。

### 格式限制

本版本公开固定的 `VERSION` 和尺寸上限常量。即使数据字节数未超过限制，也仍需要校验字段数量与指令布局，不能仅依赖文件长度判断有效性。

### 公开类型

- `DecodeErrorKind`：解码错误类别枚举。
- `DecodeError { kind: DecodeErrorKind; offset: int64; detail: int64; }`：错误类型、偏移和详情。
- `Constant`：包含原始位模式与数据的常量记录。
- `Capture`：闭包捕获记录。
- `Function`：函数名称、参数、局部槽、捕获及指令内容。
- `File`：Mochi 文件的结构化描述。
- `DecodeResult { value: File?; error: DecodeError?; }`：可空值与解码错误。
- `Summary`：文件内容统计。

### 公开常量

`VERSION = 14`：本标签中的最新 Mochi 版本。
`MAX_FILE_SIZE`、`MAX_CONSTANTS`、`MAX_GLOBALS`、`MAX_STRING_BYTES`、`MAX_INSTRUCTION_BYTES`、`MAX_FUNCTIONS`、`MAX_FUNCTION_SLOTS`：解码器公开的资源上限。

### 公开函数（5 个）

以下签名保留已实现的函数名称、参数类型和返回类型。`unit` 表示无普通返回值；`T?` 与 `Error?` 需要根据 API 语义处理 `mu`。

| 函数 | 公开签名 | 功能与返回规则 |
| --- | --- | --- |
| `decode` | `decode(data: []uint8) -> DecodeResult` | 解码并验证字节数组，不修改原输入。 |
| `error_code` | `error_code(error: DecodeError) -> int64` | 将错误类别映射为稳定的整数分类。 |
| `canonical_bytes` | `canonical_bytes(value: File) -> []uint8` | 对有效的解码结果规范化重新编码。 |
| `summarize` | `summarize(value: File) -> Summary` | 统计字节码版本、常量与函数数量等信息。 |
| `decode_file` | `decode_file(path: string) -> DecodeResult` | 从文件读取字节码并进行解码与校验。 |

### 完整示例

```mio title="Mochi.mio" no-run
yobu "kiso/encoding/mochi";

kaku input: []uint8 = [];
kaku result = mochi.decode(input);
chant(result.error != mu);
```

### 使用限制

此包是 Mochi 格式开发接口，不代表任意人工构造的 `File` 都能安全重编码。它可用于 Go 引导 CLI / Mochi VM 环境；不据此承诺 Native AOT 或纯 Mio 编译器已支持同样的工作流。
