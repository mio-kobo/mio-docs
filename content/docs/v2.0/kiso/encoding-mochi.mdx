## 函数

签名中的参数名及类型保持源码原样；下文说明参数含义、返回值及错误。除明确返回错误值的路径外，数组分配、转换和 VM 指令预算等资源限制仍可能导致运行时错误。

### decode

```text
koukai waza decode(data: []uint8) -> DecodeResult
```

参数：`data`：输入字节数组；是否复制见返回语义。

解码并验证 data，不修改输入；失败返回 DecodeResult.error，成功返回 file。

### error_code

```text
koukai waza error_code(error: DecodeError) -> int64
```

参数：`error`：待分类的 DecodeError。

将 DecodeError.kind 映射为差分测试使用的稳定整数分类。

### canonical_bytes

```text
koukai waza canonical_bytes(value: File) -> []uint8
```

参数：`value`：当前函数要处理的值或对象，类型见签名。

对有效解码 File 确定性重编码；不承诺任意手工伪造 File 都能安全编码。

### summarize

```text
koukai waza summarize(value: File) -> Summary
```

参数：`value`：当前函数要处理的值或对象，类型见签名。

对有效 File 返回版本、全局/常量/函数数量、指令总字节数和规范化长度。

### decode_file

```text
koukai waza decode_file(path: string) -> DecodeResult
```

参数：`path`：宿主文件系统路径字符串。

按 path 分块读取并在增长前检查 64 MiB 上限；I/O 失败变成 DecodeErrorKind.IoFailure。
