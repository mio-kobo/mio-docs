完整索引见 [Bunko API 参考](/docs/v2.0/kiso/api)；本页保留逐函数签名、参数、返回值、错误与示例。

UTF-8 字节语义查找、转换及 StringBuilder。不处理 Unicode 规范化、大小写折叠或字素簇；索引与容量单位均为字节。Builder 值复制共享 buffer。

支持范围：本页示例通过 Go 引导 CLI / Mochi VM 验证；错误分支覆盖范围见 [验证报告](/docs/v2.0/tooling/verification)，不表示每个函数的每条分支均实测。Native AOT 与纯 Mio 后端需按 [当前阶段](/docs/v2.0/internals/native-aot) 单独评估。

## 函数

签名中的参数名及类型保持源码原样；下文说明参数含义、返回值及错误。除明确返回错误值的路径外，数组分配、转换和 VM 指令预算等资源限制仍可能导致运行时错误。

### to_bytes

```text
koukai waza to_bytes(value: string) -> []uint8
```

参数：`value`：本次操作的输入值，返回语义及限制如下。

复制 value 的 UTF-8 字节到新数组，修改数组不会修改字符串。

### from_utf8

```text
koukai waza from_utf8(data: []uint8) -> string?
```

参数：`data`：输入字节数组；是否复制见返回语义。

严格校验 data；合法时返回独立字符串副本，非法时返回 mu。

### byte_len

```text
koukai waza byte_len(value: string) -> int64
```

参数：`value`：本次操作的输入值，返回语义及限制如下。

返回 value 的字节数，O(1)。

### rune_count

```text
koukai waza rune_count(value: string) -> int64
```

参数：`value`：本次操作的输入值，返回语义及限制如下。

返回 Unicode 标量值数量；若宿主传入非法 UTF-8 字符串，产生运行时错误。

### has_prefix

```text
koukai waza has_prefix(value: string, prefix: string) -> bool
```

参数：`value`：本次操作的输入值，返回语义及限制如下；`prefix`：待匹配前缀。

按字节比较 value 的 prefix。

### has_suffix

```text
koukai waza has_suffix(value: string, suffix: string) -> bool
```

参数：`value`：本次操作的输入值，返回语义及限制如下；`suffix`：待匹配后缀。

按字节比较 value 的 suffix。

### index

```text
koukai waza index(value: string, pattern: string) -> int64
```

参数：`value`：本次操作的输入值，返回语义及限制如下；`pattern`：待查找的字符串模式。

返回 pattern 首次出现的 UTF-8 字节偏移；未找到为 -1，空 pattern 为 0。

### contains

```text
koukai waza contains(value: string, pattern: string) -> bool
```

参数：`value`：本次操作的输入值，返回语义及限制如下；`pattern`：待查找的字符串模式。

返回 value 是否包含 pattern，空模式为真。

### concat

```text
koukai waza concat(left: string, right: string) -> string
```

参数：`left`：左侧输入；`right`：右侧输入。

返回 left 与 right 拼接后的独立字符串。

### new_builder

```text
koukai waza new_builder() -> StringBuilder
```

参数：无。

返回空 StringBuilder。

### builder_with_capacity

```text
koukai waza builder_with_capacity(capacity: int64) -> StringBuilder
```

参数：`capacity`：预留容量；字节容器按字节，普通数组按元素。

创建空 Builder，capacity 按字节预留；负容量或资源不足报错。

### write_string

```text
koukai waza write_string(builder: StringBuilder, value: string) -> unit
```

参数：`builder`：待操作共享字符串构造器；`value`：本次操作的输入值，返回语义及限制如下。

将 value 的字节追加到 builder，返回 unit。

### write_rune

```text
koukai waza write_rune(builder: StringBuilder, value: rune) -> unit
```

参数：`builder`：待操作共享字符串构造器；`value`：本次操作的输入值，返回语义及限制如下。

将 value 编码并追加到 builder；非法 Unicode 标量值报运行时错误。

### builder_len

```text
koukai waza builder_len(builder: StringBuilder) -> int64
```

参数：`builder`：待操作共享字符串构造器。

返回当前 builder 字节长度。

### builder_capacity

```text
koukai waza builder_capacity(builder: StringBuilder) -> int64
```

参数：`builder`：待操作共享字符串构造器。

返回 builder 字节容量。

### builder_reset

```text
koukai waza builder_reset(builder: StringBuilder) -> unit
```

参数：`builder`：待操作共享字符串构造器。

将共享 buffer 长度置零并保留容量。

### builder_string

```text
koukai waza builder_string(builder: StringBuilder) -> string
```

参数：`builder`：待操作共享字符串构造器。

返回独立不可变字符串副本；外部若污染 buffer 为非法 UTF-8，报运行时错误。

## 完整示例

```mio fixture="string"
yobu "kiso/string";
chant(string.byte_len("澪A"));
chant(string.rune_count("澪A"));
chant(string.index("澪A", "A"));
kaku builder = string.new_builder();
string.write_string(builder, "Mio");
string.write_rune(builder, '!');
chant(string.builder_string(builder));
kaku invalid: []uint8 = [255];
chant(string.from_utf8(invalid) == mu);
```

预期 stdout（逐字节匹配，末尾有换行）：

```text title="output"
4
2
3
Mio!
hai
```
