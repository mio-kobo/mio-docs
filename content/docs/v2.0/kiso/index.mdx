本栏目对应 **Mio v2.0.0**（标签 `v2.0.0`，提交 `0ce04dd06c6c6e4e26f55a2c0b4ffb23aa942a0a`）。Bunko 是物理 `bunko/` 根，Kiso 是公开导入路径；例如 `yobu "kiso/math";`，不要加入 `bunko/` 前缀。

## 如何读 API

每个函数先列源码原始签名，再说明输入、返回、错误和存储共享。`unit` 表示没有普通返回值；`T?` 用 `mu` 表示缺失；`Error?` 返回 `mu` 通常表示成功，返回非空错误表示失败。带 `error` 的 Result 应先检查错误再读有效负载。

长度和偏移须看单位：数组按元素，字节与路径/字符串索引规则按各包说明。`clone` 的独立存储不必然意味着递归深复制。动态分配还受 VM 资源预算影响，返回错误值的 API 不保证能捕获一切资源错误。

## 快速示例

```mio title="math.mio"
yobu "kiso/math";

kaku value: float64 = 144.0;
chant(math.sqrt(value));
chant(math.gcd(84, 30));
```

```text title="output"
12
6
```

```mio title="array.mio"
yobu "kiso/array";

kaku numbers = [10, 20];
array.push(numbers, 30);
chant(len(numbers));
chant(numbers[2]);
```

```text title="output"
3
30
```

`yobu` 的默认限定名取路径末段，因此 `kiso/math` 使用 `math.sqrt(...)`，`kiso/array` 使用 `array.push(...)`。

## 支持边界

- 基础包在 Mochi VM 路径下记录和验证；Native 支持集合小于 VM。
- `kiso/testing` 只在 `mio test` 环境注册，普通 `run` 不能使用。
- `kiso/aot/*` 与 `kiso/encoding/mochi` 是工具链接口，公开声明不表示 API 稳定或自举已验收。
- 私有 `__...` 原语与 `mio/fs/runtime` 宿主 ABI 不是普通 Kiso 公共兼容承诺。
