## Bunko 标准库

Bunko 是 Mio 的标准库集合，公开的基础模块使用 `kiso/` 作为导入路径。模块名称与源文件的物理目录相对应，使用时不应将 `bunko/` 加入导入语句。

本目录按 Mio **v2.0.0** 发布标签的实际源码整理，介绍已公开的类型、函数和常量。每个包独立成篇，文中示例采用 Mio 语法，不包含输出结果段落。

### 网页 Playground 与 CLI

网页 Playground 当前仅内置 `kiso/math`、`kiso/array`、`kiso/string`、`kiso/bytes` 和 `kiso/utf8`。这五个模块的代码示例都能作为独立代码块编译：每段均包含自己的 `yobu` 语句。

其余标准库和 AOT 工具链需要 Mio V2.0.0 CLI 与完整 Bunko。`kiso/testing` 则需要 `mio test`；对应示例不会显示网页运行按钮。

### 基础标准库

- [`kiso/math`](/docs/v2.0/kiso/math)：数学，17 个公开函数。
- [`kiso/array`](/docs/v2.0/kiso/array)：数组，8 个公开函数。
- [`kiso/string`](/docs/v2.0/kiso/string)：字符串，17 个公开函数。
- [`kiso/bytes`](/docs/v2.0/kiso/bytes)：字节，18 个公开函数。
- [`kiso/utf8`](/docs/v2.0/kiso/utf8)：UTF-8 编解码，7 个公开函数。
- [`kiso/convert`](/docs/v2.0/kiso/convert)：类型转换，10 个公开函数。
- [`kiso/path`](/docs/v2.0/kiso/path)：路径，8 个公开函数。
- [`kiso/io`](/docs/v2.0/kiso/io)：输入输出，7 个公开函数。
- [`kiso/fs`](/docs/v2.0/kiso/fs)：文件系统，16 个公开函数。
- [`kiso/encoding/binary`](/docs/v2.0/kiso/encoding-binary)：二进制编码，61 个公开函数。

### 测试与格式库

- [`kiso/testing`](/docs/v2.0/kiso/testing)：测试，2 个公开函数。
- [`kiso/encoding/mochi`](/docs/v2.0/kiso/encoding-mochi)：Mochi 格式编码，5 个公开函数。

### AOT 编译工具链

这些包为工具链开发提供指令编码、类型分析和 Mach-O 生成等接口；不应将它们当作稳定的应用层 ABI。

- [`kiso/aot/arm64`](/docs/v2.0/kiso/aot-arm64)：ARM64 指令编码，63 个公开函数。
- [`kiso/aot/lower`](/docs/v2.0/kiso/aot-lower)：AOT 降低编译，5 个公开函数。
- [`kiso/aot/lower/nativefs`](/docs/v2.0/kiso/aot-lower-nativefs)：AOT NativeFS 桥接，6 个公开函数。
- [`kiso/aot/lower/types`](/docs/v2.0/kiso/aot-lower-types)：AOT 类型分析，10 个公开函数。
- [`kiso/aot/macho`](/docs/v2.0/kiso/aot-macho)：Mach-O 文件生成，5 个公开函数。

### 选择与使用

使用数组、字符串或数字处理时，优先选择对应的基础包。涉及磁盘文件时请使用 `kiso/fs` 并检查返回错误；需要字节流时使用 `kiso/io`；测试请使用 `mio test` 和 `kiso/testing`。对于 `T?`、错误结果和共享引用，需要按照每个包的说明处理。
