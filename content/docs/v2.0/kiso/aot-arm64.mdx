## ARM64 指令编码

ARM64 指令编码模块提供 Darwin ARM64 AOT 编译器使用的指令字生成函数、错误枚举与带标签修补的汇编器。

它主要面向编译器工具链开发，不是高层数值运算库。所有编码函数返回 `Instruction`，应在使用 `word` 之前检查其可空的 `error` 字段。

本模块属于 **AOT 编译工具链接口**，其公开声明不等于稳定的应用层 API；以下内容对应 `v2.0.0` 发布标签。

### 导入包

> **运行环境：** 当前网页 Playground 的 WASM 不包含此包。以下代码示例使用 Mio V2.0.0 CLI 与完整 Bunko 标准库，网页中仅展示代码，不提供无法运行的「运行」按钮。

通过 `yobu "kiso/aot/arm64";` 导入本包，随后使用 `arm64.函数名(...)` 调用。

```mio title="Stdlib.mio"
yobu "kiso/aot/arm64";
```

### 基础指令编码

`movz_x`、`movk_x`、`add_x`、`sub_x`、`ldr_x` 等函数接收寄存器编号和偏移量，按架构规则计算 32 位机器指令字。非法寄存器或超范围操作数通过 `EncodeError` 报告。

```mio title="Arm64.mio" no-run
yobu "kiso/aot/arm64";

kaku instruction = arm64.ret();
chant(instruction.error == mu);
```

### 分支与地址

`b`、`bl`、`b_cond` 及 `cbz_x`、`cbnz_x` 等函数接收相对偏移。需要按名称建立分支时，可通过汇编器标签与修补列表处理，而不是手工猜测距离。

### 使用 Assembler

汇编器可接收指令、标签和延后解析的分支。`assembler_assemble` 返回 `AssembleResult`；有任何编码错误时，应当检查 `error` 而不是直接使用 `words`。

```mio title="Arm64.mio" no-run
yobu "kiso/aot/arm64";

kaku code = arm64.assembler();
kaku step = arm64.ret();
kaku error = arm64.assembler_emit(code, step);
chant(error == mu);
```

### v2.0.0 新增查询

本标签还公开 `assembler_label_word`，用于按标签名称查询汇编器内部的指令字位置。某些旧版文档未列出它，本文以 `v2.0.0` 源码为准。

### 公开类型

- `EncodeError`：包含非法寄存器、立即数、偏移和标签问题的枚举。
- `Instruction { word: uint32; error: EncodeError?; }`：单条编码结果。
- `Label { name: string; word: int64; }`：标签名称与指令字索引。
- `Fixup { at_word: int64; target: string; kind: int64; operand: int64; }`：分支修补项。
- `Assembler { words: []uint32; labels: []Label; label_index: [][]int64; fixups: []Fixup; errors: []EncodeError; }`：汇编缓冲区。
- `AssembleResult { words: []uint32; error: EncodeError?; }`：汇编完成结果。

### 完整示例

```mio title="Arm64.mio" no-run
yobu "kiso/aot/arm64";

kaku good = arm64.ret();
chant(good.error == mu);
kaku bad = arm64.movz_x(-1, 0, 0);
chant(bad.error != mu);
```

### 使用限制

寄存器编号、立即数字宽度、偏移方向和字节/指令字单位都必须符合 ARM64 架构规则。该模块只负责编码与汇编辅助，不负责生成可执行文件的完整布局或代码签名；输出原始指令字时仍须经过调用方校验。
