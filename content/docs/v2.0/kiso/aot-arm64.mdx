**V2.0 Development**，提交 `8b53a25142b0da1192a6c4868e807385d7bb50f9`。**V1.0 不提供本包**。公开声明不代表稳定 API；本页仅承诺此快照已有声明及明确列出的验证。

把受限 AArch64 指令编码为 `Instruction`，并以 Assembler 记录标签与 fixup。它只构造指令，不会在 VM 内执行 ARM64 指令。寄存器编号范围为 0..31；编码错误保存在返回值 error 中，error 非空时不得发射 word。

## 类型与常量

```text
koukai sentaku EncodeError {
    InvalidRegister;
    InvalidImmediate;
    InvalidCondition;
    MisalignedOffset;
    BranchOutOfRange;
    DuplicateLabel(string);
    UndefinedLabel(string);
    InvalidPatch;
}

koukai kata Instruction { word: uint32; error: EncodeError?; }

koukai kata Label { name: string; word: int64; }

koukai kata Fixup { at_word: int64; target: string; kind: int64; operand: int64; }

koukai kata Assembler { words: []uint32; labels: []Label; fixups: []Fixup; errors: []EncodeError; }

koukai kata AssembleResult { words: []uint32; error: EncodeError?; }
```

类型字段为实际公开布局；复制含数组字段的值仍共享数组。不得把公开字段解释为可安全伪造内部状态的许可。

### movz_x

```text
koukai waza movz_x(rd: int64, immediate: int64, shift: int64) -> Instruction
```

参数：`rd`：目的寄存器编号（0..31）；`immediate`：待编码立即数；范围按具体编码检查；`shift`：MOV-wide 的 16 位半字选择，0..3。

构造 MOVZ_X 编码，返回 Instruction；成功 error=mu，失败 word 不可使用。 immediate 为 0..65535，shift 是 0..3 的半字选择，超范围返回 InvalidImmediate。 寄存器编号越界返回 InvalidRegister。
