## UTF-8 编解码

UTF-8 标准库（UTF-8）用于严格验证、解码和编码 Unicode 标量值，输入输出主要是 `[]uint8` 字节数组。

与 `kiso/string` 的文本操作不同，本包面向字节级编解码，适合文件格式和数据协议的实现。

本页以 Mio `v2.0.0` 已实现的公开接口为准，不包含未实现的函数或语言语法。

### 导入包

> **网页运行说明：** 本页的 Playground 代码块都是独立程序，已分别加入所需的 `yobu` 导入语句。点击「运行」时不会继承页面中其他代码块的状态。

通过 `yobu "kiso/utf8";` 导入本包，随后使用 `utf8.函数名(...)` 调用。

```mio title="Stdlib.mio"
yobu "kiso/utf8";
```

### 验证与统计

`valid` 检查数组是否为合法 UTF-8，`rune_count` 返回 Unicode 标量值的数量。统计失败时返回 `mu`。

```mio title="Utf8.mio"
yobu "kiso/utf8";

kaku data = utf8.encode_rune('澪');
chant(utf8.valid(data));
chant(utf8.rune_count(data) != mu);
```

### 解码一个字符

`decode_one` 从指定字节偏移解码，返回 `DecodeResult`。除了 `value`，还需要检查 `valid` 和 `width`：非法序列同样可能返回 U+FFFD，不能单凭字符值判断失败。

```mio title="Utf8.mio"
yobu "kiso/utf8";

kaku bytes = utf8.encode_rune('你');
kaku result = utf8.decode_one(bytes, 0);
chant(result.valid);
chant(result.width);
```

### 写入一个字符

`encode_rune` 返回新数组；`append_rune` 向已存在的字节数组追加编码结果。非法 Unicode 标量会发生运行时错误。

```mio title="Utf8.mio"
yobu "kiso/utf8";

kaku data: []uint8 = [];
utf8.append_rune(data, 'A');
```

### 公开类型

- `DecodeResult { value: rune; width: int64; valid: bool; }`：单个 Unicode 标量值的解码结果。

### 公开函数（7 个）

以下签名保留已实现的函数名称、参数类型和返回类型。`unit` 表示无普通返回值；`T?` 与 `Error?` 需要根据 API 语义处理 `mu`。

| 函数 | 公开签名 | 功能与返回规则 |
| --- | --- | --- |
| `is_valid_rune` | `is_valid_rune(value: rune) -> bool` | 判断整数是否为合法 Unicode 标量值。 |
| `rune_width` | `rune_width(value: rune) -> int64` | 获取合法标量的 UTF-8 编码宽度，范围为 1—4 字节。 |
| `decode_one` | `decode_one(data: []uint8, offset: int64) -> DecodeResult` | 从字节偏移解码；结果包含 `value`、`width` 和 `valid`。 |
| `encode_rune` | `encode_rune(value: rune) -> []uint8` | 将一个合法标量编码为新字节数组。 |
| `append_rune` | `append_rune(destination: []uint8, value: rune) -> unit` | 将 UTF-8 编码追加到目标数组。 |
| `valid` | `valid(data: []uint8) -> bool` | 检查整个字节数组是否为严格合法的 UTF-8。 |
| `rune_count` | `rune_count(data: []uint8) -> int64?` | 返回标量值数量；非法 UTF-8 返回 `mu`。 |

### 完整示例

```mio title="Utf8.mio"
yobu "kiso/utf8";

kaku data = utf8.encode_rune('澪');
kaku result = utf8.decode_one(data, 0);
chant(result.valid);
chant(result.width);
chant(result.value);
kaku end = utf8.decode_one(data, len(data));
chant(end.width);
kaku invalid: []uint8 = [255];
chant(utf8.rune_count(invalid) == mu);
```

### 使用限制

本包不处理显示宽度、Unicode 规范化或字素簇。`decode_one` 在非法序列时返回替换字符及 `valid = iie`，到达末尾时宽度为零；其他越界偏移会发生运行时错误。
