浏览器 WASM 只内置 `kiso/math`、`kiso/array`、`kiso/string`、`kiso/bytes`、`kiso/utf8`。这些模块的示例会自动显示 Playground。其他模块没有浏览器实现，示例会标记为 `no-run`，只能使用对应版本的 CLI 与完整 Bunko 运行；不提供模拟输出。

## 应用 API

### kiso/math

导入方式：`yobu "kiso/math";`  
浏览器 Playground：可用。

数值泛型与整数/浮点数学。`checked_*` 返回 `T?`，溢出时返回 `mu`；非 checked 版本报运行时错误。`clamp` 在 `lower > upper` 时报错。

常量：`pi32`、`pi64`、`tau32`、`tau64`。

逐函数参数、返回值、错误与示例见 [kiso/math](/docs/v2.0/kiso/math)。

| 函数 | 签名 | 返回 / 可空 | 说明 | 调用示例 |
| --- | --- | --- | --- | --- |
| [`min`](/docs/v2.0/kiso/math#min) | `min<T: Number>(left: T, right: T) -> T` | `T` | 返回 left/right 较小值；传播 NaN，相等零选择负零。 | `math.min[int64](1, 2)` |
| [`max`](/docs/v2.0/kiso/math#max) | `max<T: Number>(left: T, right: T) -> T` | `T` | 返回 left/right 较大值；传播 NaN，相等零选择正零。 | `math.max[int64](1, 2)` |
| [`checked_abs`](/docs/v2.0/kiso/math#checked_abs) | `checked_abs<T: Signed>(value: T) -> T?` | `T?`（`mu`） | 返回 value 的绝对值；有符号整数最小值无法表示时返回 mu。 | `math.checked_abs[int64](1)` |

| [`is_nan`](/docs/v2.0/kiso/math#is_nan) | `is_nan<T: Float>(value: T) -> bool` | `bool` | 返回 value 是否 NaN。 | `math.is_nan[float64](1.5)` |
| [`is_inf`](/docs/v2.0/kiso/math#is_inf) | `is_inf<T: Float>(value: T) -> bool` | `bool` | 返回 value 是否任一符号 Infinity。 | `math.is_inf[float64](1.5)` |

### kiso/array

导入方式：`yobu "kiso/array";`  
浏览器 Playground：可用。

动态数组，变量、参数与返回值共享后备存储。资源不足、负长度或非法截断产生运行时错误。

逐函数参数、返回值、错误与示例见 [kiso/array](/docs/v2.0/kiso/array)。

| 函数 | 签名 | 返回 / 可空 | 说明 | 调用示例 |
| --- | --- | --- | --- | --- |
| [`make`](/docs/v2.0/kiso/array#make) | `make<T>(length: int64, initial: T) -> []T` | `[]T` | `length` 个元素，均初始化为 `initial`。若 initial 含引用，各元素仍共享该引用。负长度、容量溢出或资源不足报运行时错误。 | `array.make[int64](1, 1)` |
| [`with_capacity`](/docs/v2.0/kiso/array#with_capacity) | `with_capacity<T>(capacity: int64) -> []T` | `[]T` | 为元素类型 T 创建长度 0、预留 capacity 的数组；类型不能推断时用 `[T]`。负容量或超限报错。 | `array.with_capacity[int64](1)` |
| [`push`](/docs/v2.0/kiso/array#push) | `push<T>(values: []T, value: T) -> unit` | `unit` | 向 values 原地追加 value，返回 unit；别名可见，必要时扩容。资源不足报错。 | `array.push[int64]([1, 2], 1)` |
| [`capacity`](/docs/v2.0/kiso/array#capacity) | `capacity<T>(values: []T) -> int64` | `int64` | 返回 values 已分配元素容量，不是长度。 | `array.capacity[int64]([1, 2])` |
| [`reserve`](/docs/v2.0/kiso/array#reserve) | `reserve<T>(values: []T, additional: int64) -> unit` | `unit` | 确保可额外容纳 additional 个元素，不改变长度与已有内容；additional 不能为负，溢出或超限报错。 | `array.reserve[int64]([1, 2], 1)` |
| [`clone`](/docs/v2.0/kiso/array#clone) | `clone<T>(values: []T) -> []T` | `[]T` | 返回独立后备数组，浅复制元素；嵌套引用仍共享，分配受资源上限约束。 | `array.clone[int64]([1, 2])` |

| [`append_all`](/docs/v2.0/kiso/array#append_all) | `append_all<T>(destination: []T, source: []T) -> unit` | `unit` | 向 destination 批量追加 source 当前元素；支持自追加，按追加前长度处理，溢出或资源不足报错。 | `array.append_all[int64]([1, 2], [1, 2])` |

示例（可在浏览器运行）：

```mio title="array.mio"
yobu "kiso/array";
kaku values = array.make(2, 7);
array.push(values, 9);
chant(len(values));
chant(values[2]);
```

## 工具链与测试 API

### kiso/testing

导入方式：`yobu "kiso/testing";`  
分类：测试专用；浏览器 Playground：不可用。

只由 `mio test` 注册；普通 `run`/`check` 没有测试报告接口。

详细说明见 [kiso/testing](/docs/v2.0/kiso/testing)。

| 函数 | 签名 | 返回 / 可空 | 说明 | 调用示例 |
| --- | --- | --- | --- | --- |
| [`expect`](/docs/v2.0/kiso/testing#expect) | `expect(condition: bool, message: string) -> unit` | `unit` | condition 为 iie 时记录 message 失败；不会通过异常中断当前函数。 | `testing.expect(hai, "message")` |
| [`fail`](/docs/v2.0/kiso/testing#fail) | `fail(message: string) -> unit` | `unit` | 无条件记录 message 失败。 | `testing.fail("message")` |

### kiso/encoding/mochi

导入方式：`yobu "kiso/encoding/mochi";`  
分类：工具链 API；浏览器 Playground：不可用。

Mochi v1–v14 解码、规范化与摘要。属于工具链 API；解码失败通过 `DecodeResult.error` 返回。

结构体：`DecodeError`、`Constant`、`Capture`、`Function`、`File`、`DecodeResult`、`Summary`；枚举：`DecodeErrorKind`；常量：`VERSION`、`MAX_FILE_SIZE`、`MAX_CONSTANTS`、`MAX_GLOBALS`、`MAX_STRING_BYTES`、`MAX_INSTRUCTION_BYTES`、`MAX_FUNCTIONS`、`MAX_FUNCTION_SLOTS`。

详细说明见 [kiso/encoding/mochi](/docs/v2.0/kiso/encoding-mochi)。

| 函数 | 签名 | 返回 / 可空 | 说明 | 调用示例 |
| --- | --- | --- | --- | --- |
| [`decode`](/docs/v2.0/kiso/encoding-mochi#decode) | `decode(data: []uint8) -> DecodeResult` | `DecodeResult`（检查 `.error`） | 解码并验证 data，不修改输入；失败返回 DecodeResult.error，成功返回 file。 | `mochi.decode([])` |
| [`error_code`](/docs/v2.0/kiso/encoding-mochi#error_code) | `error_code(error: DecodeError) -> int64` | `int64` | 将 DecodeError.kind 映射为差分测试使用的稳定整数分类。 | `mochi.error_code(error)` |
| [`canonical_bytes`](/docs/v2.0/kiso/encoding-mochi#canonical_bytes) | `canonical_bytes(value: File) -> []uint8` | `[]uint8` | 对有效解码 File 确定性重编码；不承诺任意手工伪造 File 都能安全编码。 | `mochi.canonical_bytes(file)` |
| [`summarize`](/docs/v2.0/kiso/encoding-mochi#summarize) | `summarize(value: File) -> Summary` | `Summary` | 对有效 File 返回版本、全局/常量/函数数量、指令总字节数和规范化长度。 | `mochi.summarize(file)` |
