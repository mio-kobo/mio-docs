## 数组

数组标准库（Array）为 `[]T` 动态数组提供创建、追加、容量管理、浅复制与截断操作。数组类型属于语言本身，动态操作通过 `kiso/array` 提供。

数组赋值和函数传参共享底层存储，因此对元素或长度的修改会被其他引用观察到。

本页以 Mio `v2.0.0` 已实现的公开接口为准，不包含未实现的函数或语言语法。

### 导入包

> **网页运行说明：** 本页的 Playground 代码块都是独立程序，已分别加入所需的 `yobu` 导入语句。点击「运行」时不会继承页面中其他代码块的状态。

通过 `yobu "kiso/array";` 导入本包，随后使用 `array.函数名(...)` 调用。

```mio title="Stdlib.mio"
yobu "kiso/array";
```

### 创建动态数组

可以通过数组字面量 `[1, 2]` 建立数组，也可以使用 `array.make()` 指定初始长度，或者使用 `array.with_capacity()` 预留容量。长度和容量是两个独立概念。

```mio title="Array.mio"
yobu "kiso/array";

kaku a = array.make(3, 0);
kaku b = array.with_capacity[int64](10);
chant(len(a));
chant(array.capacity(b));
```

### 追加与预留

`push` 追加一个元素；`append_all` 将来源数组当时的元素批量追加到目标数组。`reserve` 只保证后续容量，不改变数组长度。

```mio title="Array.mio"
yobu "kiso/array";

kaku values = [1, 2];
array.push(values, 3);
array.reserve(values, 10);
```

### 共享与复制

普通赋值只复制数组引用。`clone` 创建独立的后备数组，但其元素按浅复制规则处理；嵌套数组仍可能共享内部引用。

```mio title="Array.mio"
yobu "kiso/array";

kaku original = [10, 20];
kaku alias = original;
alias[0] = 30;
kaku independent = array.clone(original);
```

### 缩短数组

`truncate` 将数组的共享长度缩短到指定位置，不负责选择中间子区间。Mio V2.0 目前没有数组切片表达式。

```mio title="Array.mio"
yobu "kiso/array";

kaku numbers = [1, 2, 3, 4];
array.truncate(numbers, 2);
```

### 公开函数（8 个）

以下签名保留已实现的函数名称、参数类型和返回类型。`unit` 表示无普通返回值；`T?` 与 `Error?` 需要根据 API 语义处理 `mu`。

| 函数 | 公开签名 | 功能与返回规则 |
| --- | --- | --- |
| `make` | `make<T>(length: int64, initial: T) -> []T` | 创建指定长度且所有元素初始值相同的数组；嵌套引用不自动深复制。 |
| `with_capacity` | `with_capacity<T>(capacity: int64) -> []T` | 创建长度为零、预留指定容量的数组。 |
| `push` | `push<T>(values: []T, value: T) -> unit` | 原地向末尾添加一个元素。 |
| `capacity` | `capacity<T>(values: []T) -> int64` | 获取已分配容量。 |
| `reserve` | `reserve<T>(values: []T, additional: int64) -> unit` | 保证可再容纳指定数量的元素，不改变长度。 |
| `clone` | `clone<T>(values: []T) -> []T` | 创建浅复制的独立数组。 |
| `truncate` | `truncate<T>(values: []T, new_length: int64) -> unit` | 将共享长度缩短为指定值，保留容量。 |
| `append_all` | `append_all<T>(destination: []T, source: []T) -> unit` | 批量追加源数组现有元素，允许向自身追加。 |

### 完整示例

```mio title="Array.mio"
yobu "kiso/array";

kaku original = [1, 2];
kaku alias = original;
alias[0] = 9;
array.push(alias, 3);
chant(original[0]);
kaku copied = array.clone(original);
copied[0] = 7;
array.append_all(original, original);
array.truncate(alias, 1);
chant(len(original));
```

### 使用限制

负长度、非法截断位置或资源不足会产生运行时错误。数组索引从零开始、必须位于有效长度内；`array.capacity()` 的返回值不代表这些位置已经能够直接读取。`[]T` 不支持直接相等比较或切片语法。
