## 路径

路径标准库（Path）提供路径清理、拼接、扩展名提取、目录与文件名分离等操作。

本包处理以 `/` 为分隔符的**逻辑路径字符串**，不会实际访问文件系统，也不会解析符号链接。

本页以 Mio `v2.0.0` 已实现的公开接口为准，不包含未实现的函数或语言语法。

### 导入包

> **运行环境：** 当前网页 Playground 的 WASM 不包含此包。以下代码示例使用 Mio V2.0.0 CLI 与完整 Bunko 标准库，网页中仅展示代码，不提供无法运行的「运行」按钮。

通过 `yobu "kiso/path";` 导入本包，随后使用 `path.函数名(...)` 调用。

```mio title="Stdlib.mio"
yobu "kiso/path";
```

### 清理与拼接

`clean` 去除冗余分隔符和可抵消的 `.`、`..`。`join` 处理两个部分，`join_all` 按顺序连接字符串数组并清理结果。

```mio title="Path.mio" no-run
yobu "kiso/path";

chant(path.clean("/a//b/../c/"));
chant(path.join("docs", "v2/guide.mio"));
```

### 判断与拆分

`is_abs` 判断路径是否以 `/` 开头；`base`、`dir`、`ext` 分别取得基本名称、目录和扩展名。

```mio title="Path.mio" no-run
yobu "kiso/path";

chant(path.base("docs/hello.mio"));
chant(path.ext("docs/hello.mio"));
```

### SplitResult

`split` 返回结构体，其 `dir` 和 `base` 字段分别是清理后的目录部分与末段名称。

```mio title="Path.mio" no-run
yobu "kiso/path";

kaku result = path.split("docs/main.mio");
chant(result.dir);
chant(result.base);
```

### 公开类型

- `SplitResult { dir: string; base: string; }`：分离目录与末段名称的返回结果。

### 公开函数（8 个）

以下签名保留已实现的函数名称、参数类型和返回类型。`unit` 表示无普通返回值；`T?` 与 `Error?` 需要根据 API 语义处理 `mu`。

| 函数 | 公开签名 | 功能与返回规则 |
| --- | --- | --- |
| `clean` | `clean(value: string) -> string` | 清理路径中的重复分隔符、`.` 和可抵消的 `..`。 |
| `join` | `join(left: string, right: string) -> string` | 连接两个路径片段并清理。 |
| `join_all` | `join_all(parts: []string) -> string` | 连接数组中的全部路径片段并清理。 |
| `is_abs` | `is_abs(value: string) -> bool` | 判断路径是否以 `/` 开始。 |
| `base` | `base(value: string) -> string` | 返回路径最后一段。 |
| `dir` | `dir(value: string) -> string` | 返回清理后的目录部分。 |
| `ext` | `ext(value: string) -> string` | 返回基本名称中的扩展名，`.env` 不视为有扩展名。 |
| `split` | `split(value: string) -> SplitResult` | 返回包含 `dir` 和 `base` 的结果结构体。 |

### 完整示例

```mio title="Path.mio" no-run
yobu "kiso/path";

chant(path.clean("/a//b/../c/"));
chant(path.clean(""));
chant(path.join("a", "/b"));
chant(path.ext(".env"));
kaku result = path.split("a/b.mio");
chant(result.dir);
chant(result.base);
```

### 使用限制

这里的路径算法不认识 Windows 盘符、UNC 路径或反斜杠，也不验证文件是否存在。特别注意 `join("a", "/b")` 的规则不同于某些语言的路径库：第二段以 `/` 开头不代表自动抛弃第一段。
