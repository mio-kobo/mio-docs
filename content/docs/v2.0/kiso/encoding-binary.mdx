## 二进制编码

二进制编码标准库（Binary Encoding）用于读取和写入有符号整数、无符号整数、大小端数据与可变长度整数，并提供具有偏移状态的 Reader 和 Writer。

二进制偏移都按**字节**计算。本包提供 `U64` 结构表示无符号 64 位位模式，不表示 Mio 存在内置的 `uint64` 数值类型。

本页以 Mio `v2.0.0` 已实现的公开接口为准，不包含未实现的函数或语言语法。

### 导入包

> **运行环境：** 当前网页 Playground 的 WASM 不包含此包。以下代码示例使用 Mio V2.0.0 CLI 与完整 Bunko 标准库，网页中仅展示代码，不提供无法运行的「运行」按钮。

通过 `yobu "kiso/encoding/binary";` 导入本包，随后使用 `binary.函数名(...)` 调用。

```mio title="Stdlib.mio"
yobu "kiso/encoding/binary";
yobu "kiso/array";
```

### 读取定宽数据

例如，`read_i64_be` 按大端规则读取八个字节并返回 `I64Result`。所有读取都应检查结果中的 `error`，不能仅凭 `value` 判断成功。

```mio title="Binary.mio" no-run
yobu "kiso/encoding/binary";
yobu "kiso/array";

kaku data: []uint8 = [0, 0, 0, 0, 0, 0, 0, 42];
kaku result = binary.read_i64_be(data, 0);
chant(result.error == mu);
```

### 写入定宽数据

写入函数修改已有的 `[]uint8` 元素，不会自动扩容。在写入前应确保数组有足够长度，错误通过 `BinaryError?` 返回。

```mio title="Binary.mio" no-run
yobu "kiso/encoding/binary";
yobu "kiso/array";

kaku data = array.make[uint8](8, uint8(0));
kaku error = binary.write_i64_be(data, 0, -42);
chant(error == mu);
```

### 可变长度整数

`read_var_u32`、`read_var_i64` 与配套的 `write_var_*` 函数用于可变长度编码。读取结果提供 `count`，表示本次消费的字节数。

### BinaryReader 与 BinaryWriter

Reader 保存当前位置，读取会推进游标；Writer 可顺序追加、预留、补丁式覆盖已经生成的字段。需要检查每一步返回的可空错误，最终通过 `writer_bytes` 导出副本。

```mio title="Binary.mio" no-run
yobu "kiso/encoding/binary";
yobu "kiso/array";

kaku writer = binary.writer(16);
kaku error = binary.writer_write_u32_be(writer, uint32(42));
kaku reader = binary.reader(binary.writer_bytes(writer));
kaku result = binary.reader_read_u32_be(reader);
```

### 公开类型

- `BinaryError`：解码、编码与越界类错误枚举。
- `U8Result`、`U16Result`、`U32Result`：无符号整数读取结果。
- `I8Result`、`I16Result`、`I32Result`、`I64Result`：有符号整数读取结果。
- `BytesResult { data: []uint8; error: BinaryError?; }`：字节编码结果。
- `VarU32Result`、`VarI64Result`：含 `value`、`count` 和错误的可变整数读取结果。
- `U64 { high: uint32; low: uint32; }`：无符号 64 位位模式。
- `U64Result`：64 位无符号读取结果。
- `BinaryReader { data: []uint8; state: []int64; }`：共享数组与游标状态的读取器。
- `BinaryWriter { data: []uint8; max_length: int64; }`：具有最大长度限制的写入器。

### 完整示例

```mio title="Binary.mio" no-run
yobu "kiso/encoding/binary";
yobu "kiso/array";

kaku data = array.make[uint8](8, uint8(0));
kaku error = binary.write_i64_be(data, 0, -42);
chant(error == mu);
kaku result = binary.read_i64_be(data, 0);
chant(result.value);
kaku bad = binary.read_u32_le(data, 6);
chant(bad.error != mu);
kaku writer = binary.writer(16);
kaku write_error = binary.writer_write_u32_be(writer, uint32(42));
kaku reader = binary.reader(binary.writer_bytes(writer));
kaku read_result = binary.reader_read_u32_be(reader);
chant(read_result.value);
```

### 使用限制

偏移与长度需要落在数据边界内，读取或写入失败不会自动抛出可由 Mio 捕获的异常，而是返回 `BinaryError`。`BinaryReader` 和 `BinaryWriter` 包含共享存储，复制变量时须理解其游标和内容的别名关系；不要把容量当作有效长度。
