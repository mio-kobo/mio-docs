Mio 是一门使用**日语罗马字关键字**的静态强类型编程语言。它以小巧的语言核心、明确的类型与数值语义，以及按需导入的标准库为设计方向，希望让程序的表达保持简洁，同时让每一次类型转换和数据操作都有清晰的含义。

Mio V2.0 在 Mochi 字节码与虚拟机的基础上，引入了针对 macOS Apple Silicon（ARM64）的原生 AOT 编译能力。无论是第一次接触 Mio，还是希望了解其语言设计和工具链，都可以从本页开始。

本页介绍 [Mio 特性](#mio-特性)、[使用 Mio](#使用-mio)、[语言 API](#语言-api) 和 [标准库](#标准库)。如果你想直接运行程序，可以跳转到 [安装与运行](/docs/v2.0/getting-started)。

## Mio 特性

### 熟悉而独特的语法

Mio 使用 `kaku` 声明变量、`waza` 定义函数、`moshi` 表示条件判断、`kaesu` 返回结果。这些关键字采用日语罗马字拼写，但程序中的标识符、类型标注、运算符和代码块仍遵循清晰、常见的结构化语法。

Mio 允许直接执行顶层语句，因此简单程序不需要额外编写 `main` 函数。完整的关键字、表达式和控制流规则见 [语法与表达式](/docs/v2.0/reference/syntax)。

### 静态强类型与明确的数值语义

Mio 在程序运行前执行类型检查，支持类型推断，也支持显式类型标注。不同宽度的整数、整数与浮点数之间不会随意进行隐式转换。需要转换时，应通过类型名明确写出操作。

语言提供固定宽度整数、`float32`、`float64`、`bool`、`string` 和 `rune` 等基础类型，也支持数组、Map、结构体和枚举。数值运算、溢出、转换和可空值都有明确规则，详见 [类型系统](/docs/v2.0/reference/types)。

### 泛型、Nullable 与函数式能力

Mio 支持泛型函数、泛型结构体与枚举，可以在保持类型安全的前提下复用代码。数值泛型还提供 `Number`、`Integer`、`Signed` 和 `Float` 等内建约束。

更多用法见 [函数与闭包](/docs/v2.0/reference/functions)、[数组与集合](/docs/v2.0/reference/collections) 和 [泛型与模块](/docs/v2.0/reference/modules)。

### Mochi 与原生编译

Mio 将源码编译为 **Mochi 字节码**，既可以通过 Mochi VM 执行，也可以把受支持的字节码进一步编译为原生程序。V2.0 已实现 macOS ARM64 的原生 AOT 后端，并验证了纯 Mio 原生后端的多代自编译。

需要注意的是，Mochi VM 与 Native AOT 的功能覆盖范围并不完全相同；Mio 的源码前端、VM 和 LSP 目前仍使用 Go 实现。相关原理见 [Native AOT](/docs/v2.0/internals/native-aot) 和 [运行时与 GC](/docs/v2.0/internals/gc)。

## 使用 Mio

### 安装与准备

Mio v2.0.0 已正式发布，可从 [GitHub Releases](https://github.com/mio-kobo/mio/releases/tag/v2.0.0) 获取。该版本的官方预编译发行包面向 **macOS Apple Silicon / ARM64**；其他平台尚未获得这一版本的正式支持认证。

使用官方发行包无需额外安装 Go。安装后可以使用 `mio version` 查看版本，并根据 [安装与运行教程](/docs/v2.0/getting-started) 配置 Bunko 标准库目录。

### 继续学习

如果你刚开始学习 Mio，推荐阅读 [Learn 学习教程](/docs/v2.0/learn)。教程从变量和数据类型开始，逐步介绍条件、循环、函数、数组、Map、结构体、枚举、泛型、模块和测试。

Mio 还提供 [VS Code 与 JetBrains 编辑器支持](/docs/v2.0/tooling/editors)，可配合语言工具完成日常开发。

## 标准库

Mio 的标准库称为 **Bunko**。它把语言核心以外的常用能力组织成独立模块，由程序按需导入。基础标准库使用 `kiso/` 作为公开导入路径，`bunko/` 则是安装包或源码中的物理目录，不需要写在 `yobu` 语句中。


### 常用标准库模块

| 模块 | 主要用途 |
| --- | --- |
| [`kiso/math`](/docs/v2.0/kiso/math) | 数值计算、平方根、取整和数学常量 |
| [`kiso/array`](/docs/v2.0/kiso/array) | 动态数组的追加、复制和容量操作 |
| [`kiso/string`](/docs/v2.0/kiso/string) | 字符串、UTF-8 文本与 Builder |
| [`kiso/bytes`](/docs/v2.0/kiso/bytes) | 字节序列比较、查找和修改 |
| [`kiso/convert`](/docs/v2.0/kiso/convert) | 数值与文本的转换 |
| [`kiso/io`](/docs/v2.0/kiso/io) | 同步读写接口与流操作 |
| [`kiso/fs`](/docs/v2.0/kiso/fs) | 文件和目录操作 |
| [`kiso/path`](/docs/v2.0/kiso/path) | 路径处理 |
| [`kiso/encoding/binary`](/docs/v2.0/kiso/api) | 二进制数据编码与解码 |
| [`kiso/testing`](/docs/v2.0/kiso/testing) | `mio test` 环境中的断言与测试辅助 |

关于全部公开函数、参数类型和返回值，请查看 [Bunko API 参考](/docs/v2.0/kiso/api)。
