## 路径处理 <PlatformSupport showArch={true} systems={{ macos: { arm64: "full" }, linux: { x86_64: "full" }, windows: { x86_64: "full" } }} />

路径处理标准库（`kiso/path`）为 Mio 提供纯词法（Lexical）的逻辑路径规范化、拼接、根目录判定、扩展名提取以及目录与文件名分离功能。

本模块仅处理以正斜杠 `/` 为分隔符的**逻辑路径字符串**，不会访问实际文件系统，也不会解析符号链接或探测磁盘目录结构。

### 导入包

> **网页运行说明：** 本页的 Playground 代码块均为独立可运行程序，已各自包含所需的 `yobu` 导入语句，运行时互不继承状态。

通过 `yobu "kiso/path";` 导入本包，并使用 `path.函数名(...)` 调用：

```mio title="PathImport.mio"
yobu "kiso/path";
```

### 路径规范化与拼接

`path.clean` 消除多余的连续斜杠 `/`、当前目录标记 `.` 以及可抵消的父级目录 `..`；空路径 `""` 会被规范化为 `"."`，根路径的父级不会越过 `"/"`，而相对路径开头无法抵消的 `".."` 会被保留。

`path.join` 与 `path.join_all` 使用 `/` 连接多个路径片段并对最终结果自动执行 `clean`。

```mio title="PathCleanJoin.mio"
yobu "kiso/path";

chant(path.clean(""));              // .
chant(path.clean("/a//b/../c/.")); // /a/c
chant(path.clean("../../a/../b"));  // ../../b

chant(path.join("docs", "v2.1/guide.mio"));           // docs/v2.1/guide.mio
chant(path.join("a/b", "../c"));                      // a/c
chant(path.join_all(["src", "kiso", "..", "path"]));  // src/path
```

在上述示例中，由于 `join` 仅按 `/` 拼接后规范化，`path.join("a", "/b")` 会得到 `"a/b"`（第二段开头的 `/` 不会像部分宿主路径库那样丢弃第一段）。

### 判断绝对路径与拆解路径组件

`path.is_abs` 判断路径是否以 `/` 开头；`path.base`、`path.dir` 与 `path.ext` 均先对输入执行 `clean`，再分别提取末段名称、父目录路径和文件扩展名。`path.split` 则一次性返回包含 `dir` 与 `base` 的 `SplitResult` 结构体。

```mio title="PathParts.mio"
yobu "kiso/path";

chant(path.is_abs("/usr/local")); // hai
chant(path.is_abs("src/main"));   // iie

chant(path.base("/a/b.txt/"));    // b.txt（忽略尾随斜杠）
chant(path.dir("/a/b.txt"));      // /a
chant(path.ext("/a/b.txt"));      // .txt
chant(path.ext(".env"));          // ""（隐藏文件前导点不视为扩展名）

kaku parts = path.split("docs/manual.mio");
chant(parts.dir);                 // docs
chant(parts.base);                // manual.mio
```

### 公开类型

#### `SplitResult`

```mio title="PathTypes.mio" no-run
koukai kata SplitResult {
    dir: string;  // 规范化后的父目录部分（无父目录时为 "."，根目录为 "/"）
    base: string; // 规范化后的末段基本名称
}
```

### 公开函数（8 个）

| 函数       | 公开签名                                      | 功能与返回规则                                                                                             |
| ---------- | --------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `clean`    | `clean(value: string) -> string`              | 按词法规则清理重复分隔符、`.` 与可抵消的 `..`，并移除非根目录的尾随 `/`；空输入返回 `"."`。                |
| `join`     | `join(left: string, right: string) -> string` | 使用 `/` 连接两个路径片段并调用 `clean` 返回规范化结果（空片段会被自动跳过）。                             |
| `join_all` | `join_all(parts: []string) -> string`         | 按顺序使用 `/` 连接字符串数组中的全部片段并调用 `clean`；空数组返回 `"."`。                                |
| `is_abs`   | `is_abs(value: string) -> bool`               | 判断路径字符串是否以 `/` 开头。                                                                            |
| `base`     | `base(value: string) -> string`               | 返回规范化路径的最后一段名称；若输入为 `"/"`、`"."` 或 `".."` 则原样返回。                                 |
| `dir`      | `dir(value: string) -> string`                | 返回规范化路径的父目录部分；若路径不含 `/` 则返回 `"."`，位于根目录下则返回 `"/"`。                        |
| `ext`      | `ext(value: string) -> string`                | 返回 `base(value)` 中最后一个 `.` 及其后缀（包含 `.`）；若无后缀或仅首字符为 `.`（如 `.env`）则返回 `""`。 |
| `split`    | `split(value: string) -> SplitResult`         | 对 `value` 执行 `clean` 后同时返回 `{ dir: dir(normalized), base: base(normalized) }`。                    |

### 完整示例

下面的示例演示了在纯词法路径规范化下的边界行为（包括根路径保护、相对父级保留、隐藏文件名以及反斜杠处理）：

```mio title="PathComplete.mio"
yobu "kiso/path";

// 根路径与相对路径边界
chant(path.clean("/../../etc/hosts")); // /etc/hosts
chant(path.clean("../a/b/.."));        // ../a

// 连接多段路径并拆分
kaku full = path.join_all(["bunko", "kiso", "path", "path.mio"]);
kaku info = path.split(full);
chant(info.dir);                       // bunko/kiso/path
chant(info.base);                      // path.mio
chant(path.ext(full));                 // .mio

// 隐藏文件与反斜杠行为
chant(path.ext(".gitignore"));         // ""
chant(path.clean("C:\\temp\\a.txt"));  // C:\temp\a.txt（反斜杠视为普通文件名字符）
```

### 使用限制与平台说明

- **纯逻辑正斜杠语义**：本模块始终以 `/` 作为唯一路径分隔符，不识别 Windows 盘符（如 `C:`）、反斜杠 `\` 或 UNC 网络路径（反斜杠会被当作普通文件名字符保留）；若需获取宿主操作系统的真实物理绝对路径，请使用 `kiso/os` 中的 `os.canonical_path`。
- **词法处理与安全边界**：`path.clean` 仅执行纯字符串词法折叠，不会解析磁盘上的符号链接（Symlink），也不能替代文件系统访问权限或沙箱路径逃逸校验。
