## 数组

数组标准库（`kiso/array`）为 Mio 的内置动态数组类型 `[]T` 提供元素填充创建、容量预留、原地追加、浅复制与原地截断等操作。

在 Mio 中，数组变量保存的是对底层存储的共享引用（Shared Reference）。将数组赋值给其他变量或作为参数传递给函数时，不会自动复制元素；通过任意引用修改元素或更改长度，都会反映到所有共享该数组的引用上。

### 创建动态数组

除了使用数组字面量 `[1, 2]` 外，还可以通过 `array.make` 创建指定初始长度并填充默认值的数组，或通过 `array.with_capacity` 创建长度为 `0` 但已预留底层缓冲区的空数组。

```mio title="ArrayCreate.mio"
yobu "kiso/array";

kaku filled = array.make[int64](3, 7);
kaku reserved = array.with_capacity[int64](16);

chant(len(filled));              // 3
chant(filled[2]);                // 7
chant(len(reserved));            // 0
chant(array.capacity(reserved)); // 16（或更大的已分配容量）
```

在上述示例中，长度（`len`）表示当前可安全索引的有效元素数量，容量（`capacity`）表示无需重新分配内存即可容纳的元素上限。即使 `reserved` 的容量为 `16`，在其长度大于 `0` 之前依然不能直接通过 `reserved[0]` 访问。

### 追加与预留容量

`array.push` 在数组末尾原地追加单个元素；`array.append_all` 将源数组当前包含的元素批量追加到目标数组末尾（支持将数组追加到自身）；`array.reserve` 保证底层缓冲区还能额外容纳指定数量的元素，不会改变当前数组长度。

```mio title="ArrayGrow.mio"
yobu "kiso/array";

kaku values = [10, 20];
array.push(values, 30);
array.reserve(values, 10);
array.append_all(values, [40, 50]);

chant(len(values));              // 5
chant(values[4]);                // 50
chant(array.capacity(values)); // >= 13
```

### 共享引用与浅复制

普通赋值只复制数组引用；若需要一份互不影响的独立副本，应使用 `array.clone`。`clone` 会分配新的底层存储并按**浅复制（Shallow Copy）**规则复制元素。

```mio title="ArrayClone.mio"
yobu "kiso/array";

kaku original: []int64 = [10, 20];
kaku alias = original;
alias[0] = 99;

// original 受到 alias 修改的影响
chant(original[0]); // 99

// clone 创建独立副本，修改 copied 不会影响 original
kaku copied = array.clone(original);
copied[0] = 42;
chant(original[0]); // 99
chant(copied[0]);   // 42

// 嵌套数组为浅复制：内层数组依然共享引用
kaku nested: [][]int64 = [[1, 2]];
kaku shallow = array.clone(nested);
shallow[0][0] = 88;
chant(nested[0][0]); // 88
```

### 缩短数组长度

`array.truncate` 将数组的共享长度原地缩短为 `new_length`，同时保留已分配的底层容量以便后续复用。

```mio title="ArrayTruncate.mio"
yobu "kiso/array";

kaku items: []string = ["a", "b", "c", "d"];
kaku before_cap = array.capacity(items);

array.truncate(items, 2);

chant(len(items));                        // 2
chant(items[1]);                          // b
chant(array.capacity(items) == before_cap); // hai
```

### 公开函数（8 个）

| 函数            | 公开签名                                               | 功能与参数规则                                                                                                    |
| --------------- | ------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| `make`          | `make<T>(length: int64, initial: T) -> []T`            | 创建长度为 `length`（须 `>= 0`）的数组，并将每个位置初始化为 `initial`；若 `T` 为引用类型，所有槽位共享同一引用。 |
| `with_capacity` | `with_capacity<T>(capacity: int64) -> []T`             | 创建初始长度为 `0`、底层缓冲区至少能容纳 `capacity`（须 `>= 0`）个元素的数组。                                    |
| `push`          | `push<T>(values: []T, value: T) -> unit`               | 原地向 `values` 末尾追加一个元素，必要时自动扩容。                                                                |
| `capacity`      | `capacity<T>(values: []T) -> int64`                    | 返回 `values` 当前底层缓冲区已分配的元素容量（始终 `>= len(values)`）。                                           |
| `reserve`       | `reserve<T>(values: []T, additional: int64) -> unit`   | 确保 `values` 至少还能额外容纳 `additional`（须 `>= 0`）个元素，不改变当前长度。                                  |
| `clone`         | `clone<T>(values: []T) -> []T`                         | 分配新的独立数组并浅复制 `values` 中的全部现有元素。                                                              |
| `truncate`      | `truncate<T>(values: []T, new_length: int64) -> unit`  | 原地将 `values` 的长度缩短为 `new_length`（须满足 `0 <= new_length <= len(values)`），保留原容量。                |
| `append_all`    | `append_all<T>(destination: []T, source: []T) -> unit` | 按顺序将 `source` 当前的全部元素追加到 `destination` 末尾；允许 `destination` 与 `source` 为同一数组（自追加）。  |

### 完整示例

下面的示例综合演示了引用共享、原地追加、浅复制隔离、自追加以及截断操作：

```mio title="ArrayWorkflow.mio"
yobu "kiso/array";

kaku original: []int64 = [1, 2];
kaku alias = original;

// 通过共享别名修改与追加
alias[0] = 9;
array.push(alias, 3);
chant(original[0]); // 9
chant(len(original)); // 3

// 创建独立副本
kaku copied = array.clone(original);
copied[0] = 77;
chant(original[0]); // 9

// 自追加：将 original 当前的 [9, 2, 3] 追加到自身末尾
array.append_all(original, original);
chant(len(original)); // 6
chant(original[3]);   // 9

// 截断至前 2 个元素
array.truncate(alias, 2);
chant(len(original)); // 2
```

### 使用限制与平台说明

- **边界检查与运行时错误**：`make`、`with_capacity`、`reserve` 传入负数参数，或 `truncate` 传入小于 `0` 或大于当前 `len(values)` 的目标长度，均会触发运行时错误。数组下标访问的有效范围为 `0 <= index < len(values)`，超出长度但处于 `capacity` 范围内的位置不可直接读写。
- **语法边界**：Mio V2.1 暂不支持 `values[1:3]` 切片语法，也不支持使用 `==` 直接比较两个数组的内容。
- **扩容策略**：原生 AOT 运行时下，数组最小扩容基准为 `4` 个元素；容量低于 `1024` 时按倍增策略增长，达到或超过 `1024` 后每次按 `1.5` 倍增长。
