## UTF-8 编解码

UTF-8 编解码标准库（`kiso/utf8`）提供严格的 UTF-8（RFC 3629）字节序列合法性验证、Unicode 标量值（`rune`）计数以及单字符编码与解码操作。

与面向高级文本处理的 `kiso/string` 不同，本模块直接操作 `[]uint8` 字节序列，适合用于二进制协议解析、词法扫描与自定义文本流编解码。

### 导入包

> **网页运行说明：** 本页的 Playground 代码块均为独立可运行程序，已各自包含所需的 `yobu` 导入语句，运行时互不继承状态。

通过 `yobu "kiso/utf8";` 导入本包，并使用 `utf8.函数名(...)` 调用：

```mio title="Utf8Import.mio"
yobu "kiso/utf8";
```

### 验证字节序列与统计标量值

`utf8.valid` 严格校验整个 `[]uint8` 数组是否符合 UTF-8 编码规范（拒绝过长编码、UTF-16 代理区码点 `U+D800 ~ U+DFFF`、超出 `U+10FFFF` 的码点及截断的多字节序列）；`utf8.rune_count` 在合法时返回 Unicode 标量值总数，遇到非法字节序列时返回 `mu`。

```mio title="Utf8Validate.mio"
yobu "kiso/utf8";

kaku valid_bytes: []uint8 = [65, 195, 169, 240, 159, 152, 128]; // "Aé😀"
chant(utf8.valid(valid_bytes)); // hai

kaku count = utf8.rune_count(valid_bytes);
moshi (count != mu) {
    chant(count); // 3
}

// 非法编码（如孤立续字节 0x80 或过长编码）会被严格拒绝
chant(utf8.valid([237, 160, 128]));      // iie（代理区码点）
chant(utf8.rune_count([65, 128]) == mu); // hai
```

### 逐字符解码与流式扫描

`utf8.decode_one(data, offset)` 从指定的字节偏移量解码单个 Unicode 标量值，返回 `DecodeResult`。调用方必须同时检查 `valid` 与 `width`（不能仅凭 `value == '\uFFFD'` 判断失败，因为 `U+FFFD` 本身也是合法的 Unicode 标量值）：

- **合法字符**：`valid == hai`，`width` 为 `1 ~ 4` 字节，`value` 为解码出的标量值。
- **非法字节序列**：`valid == iie`，`width == 1`，`value == '\uFFFD'`（允许调用方按单字节步进恢复扫描）。
- **到达数组末尾（`offset == len(data)`）**：`valid == iie`，`width == 0`，`value == '\uFFFD'`。

```mio title="Utf8DecodeLoop.mio"
yobu "kiso/utf8";

kaku data: []uint8 = [65, 230, 151, 165, 255]; // 'A' + '日' + 非法字节 0xFF
kaku offset = 0;

aida (offset < len(data)) {
    kaku res = utf8.decode_one(data, offset);
    chant(res.valid); // 依次输出 hai, hai, iie
    chant(res.width); // 依次输出 1, 3, 1
    offset = offset + res.width;
}

// 恰好到达末尾时返回 width == 0
kaku end = utf8.decode_one(data, len(data));
chant(end.width); // 0
```

### 编码与追加 Unicode 标量值

`utf8.encode_rune` 为单个合法 `rune` 分配精确宽度的新 `[]uint8` 数组并写入 UTF-8 字节；`utf8.append_rune` 则将编码后的 `1 ~ 4` 字节直接追加到现有目标数组末尾。

```mio title="Utf8Encode.mio"
yobu "kiso/utf8";

chant(utf8.is_valid_rune('澪')); // hai
chant(utf8.rune_width('澪'));    // 3

kaku single = utf8.encode_rune('😀');
chant(len(single));              // 4

kaku buf: []uint8 = [33];        // '!'
utf8.append_rune(buf, '中');
chant(len(buf));                 // 4 ([33, 228, 184, 173])
```

### 公开类型

#### `DecodeResult`

```mio title="Utf8Types.mio" no-run
koukai kata DecodeResult {
    value: rune;  // 解码出的 Unicode 标量值（非法输入或末尾位置固定为 '\uFFFD'）
    width: int64; // 消费的字节宽度（合法为 1~4，非法序列为 1，offset == len(data) 时为 0）
    valid: bool;  // 是否成功解码出合法的 UTF-8 字符
}
```

### 公开函数（7 个）

| 函数            | 公开签名                                                   | 功能与返回规则                                                                                                                                                                          |
| --------------- | ---------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `is_valid_rune` | `is_valid_rune(value: rune) -> bool`                       | 判断 `value` 是否为合法 Unicode 标量值（`0 <= code <= 0x10FFFF` 且不在代理区 `0xD800 ~ 0xDFFF` 内）。                                                                                   |
| `rune_width`    | `rune_width(value: rune) -> int64`                         | 返回合法 Unicode 标量值所需的 UTF-8 编码字节数（`1 ~ 4`）；传入非法 `rune` 时触发运行时错误。                                                                                           |
| `decode_one`    | `decode_one(data: []uint8, offset: int64) -> DecodeResult` | 从 `data[offset]` 解码单个标量值；非法序列返回 `{ '\uFFFD', 1, iie }`，`offset == len(data)` 返回 `{ '\uFFFD', 0, iie }`；`offset < 0` 或 `offset > len(data)` 触发数组越界运行时错误。 |
| `encode_rune`   | `encode_rune(value: rune) -> []uint8`                      | 将合法标量值 `value` 编码为长度 `1 ~ 4` 的新字节数组；传入非法 `rune` 时触发运行时错误。                                                                                                |
| `append_rune`   | `append_rune(destination: []uint8, value: rune) -> unit`   | 将合法标量值 `value` 的 UTF-8 字节原地追加到 `destination` 末尾；传入非法 `rune` 时触发运行时错误且不修改目标数组。                                                                     |
| `valid`         | `valid(data: []uint8) -> bool`                             | 检查 `data` 全部字节是否构成严格合法的 UTF-8 序列（空数组 `[]` 返回 `hai`）。                                                                                                           |
| `rune_count`    | `rune_count(data: []uint8) -> int64?`                      | 统计合法 UTF-8 字节数组中的 Unicode 标量值总数；若包含任何非法 UTF-8 序列则返回 `mu`。                                                                                                  |

### 使用限制与平台说明

- **错误处理差异**：解码与校验函数（`decode_one`、`valid`、`rune_count`）遇到非法 UTF-8 输入时通过返回值（`valid = iie` 或 `mu`）安全报告；而编码与宽度查询函数（`rune_width`、`encode_rune`、`append_rune`）传入非法码点（如负数、代理区或 `> 0x10FFFF`）时会直接触发运行时错误。
- **越界规则**：`decode_one` 仅允许 `0 <= offset <= len(data)`（其中 `offset == len(data)` 用于循环终止检测）；传入负数或大于 `len(data)` 的偏移量会触发数组下标越界运行时错误。
- **文本语义边界**：本模块仅处理 Unicode 标量值与 UTF-8 字节编码，不包含 Unicode 规范化（NFC/NFD）、大小写转换、显示宽度计算或字素簇（Grapheme Cluster）分割功能。
