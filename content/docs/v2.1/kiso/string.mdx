## 字符串

字符串标准库（`kiso/string`）为 Mio 内置的不可变 UTF-8 文本类型 `string` 提供字节长度与 Unicode 标量值计数、前缀/后缀/子串字节语义查找、字符串拼接、首尾空白修剪、UTF-8 字节数组互转以及可复用的 `StringBuilder`。

在 Mio 中，`string` 值本身是不可变的，采用 UTF-8 编码保存。语言内置 `==` 与 `!=` 用于比较字符串内容是否完全一致（区分大小写），不支持使用 `+` 运算符直接拼接字符串或对字符串进行下标赋值与切片操作。

### 字节长度与 Unicode 标量值计数

由于 UTF-8 采用变长编码（ASCII 字符占 1 字节，常见中日韩文字占 3 字节，部分 Emoji 占 4 字节），`kiso/string` 区分底层字节数与 Unicode 标量值（`rune`）数量：

- `string.byte_len`：返回字符串的 UTF-8 字节长度（$O(1)$ 读取）。
- `string.rune_count`：解码统计字符串包含的 Unicode 标量值个数。

```mio title="StringLength.mio"
yobu "kiso/string";

kaku text = "澪Mio😀";

chant(string.byte_len(text));   // 10（3 + 3 + 4 字节）
chant(string.rune_count(text)); // 5（1 + 3 + 1 个 Unicode 标量值）
```

在上述示例中，内置 `len()` 仅适用于数组，获取字符串长度请使用 `string.byte_len` 或 `string.rune_count`。

### 查找与前后缀判断

`has_prefix`、`has_suffix`、`contains` 和 `index` 均按 **UTF-8 字节序列**进行精确匹配。其中 `index` 返回子串首次出现时的**起始字节偏移量**，未找到时返回 `-1`（空模式串 `""` 始终返回 `0`）。

```mio title="StringSearch.mio"
yobu "kiso/string";

kaku path = "src/日本語.mio";

chant(string.has_prefix(path, "src/")); // hai
chant(string.has_suffix(path, ".mio")); // hai
chant(string.contains(path, "日本"));    // hai
chant(string.index(path, "語"));        // 10（"src/" 占 4 字节，"日本" 占 6 字节）
chant(string.index(path, "missing"));   // -1
```

### 拼接与首尾空白修剪

`string.concat` 按总字节长度预分配缓冲区并拼接两个字符串；V2.1 新增的 `string.trim_space` 用于去除字符串首尾的所有 Unicode 空白字符（包括 ASCII 空白 `\t`、`\n`、`\r`、空格，以及全角空格 `\u3000`、不换行空格 `\u00A0`、行分隔符 `\u2028` 等）。

```mio title="StringTrimConcat.mio"
yobu "kiso/string";

kaku raw = "　\tHello, Mio!\n ";
kaku clean = string.trim_space(raw);
kaku greeting = string.concat(clean, " v2.1");

chant(clean);    // Hello, Mio!
chant(greeting); // Hello, Mio! v2.1
```

### 字符串与 UTF-8 字节数组互转

`string.to_bytes` 将字符串复制为独立的 `[]uint8` 字节数组；`string.from_utf8` 则校验字节序列的 UTF-8 合法性（拒绝非法续字节、代理区码点及过长编码），合法时返回对应 `string`，非法时返回 `mu`。

```mio title="StringUtf8.mio"
yobu "kiso/string";

kaku raw = string.to_bytes("A日");
chant(len(raw)); // 4（[65, 230, 151, 165]）

kaku valid = string.from_utf8([230, 151, 165]);
moshi (valid != mu) {
    chant(valid); // 日
}

// 非法 UTF-8 序列返回 mu
kaku invalid = string.from_utf8([255]);
chant(invalid == mu); // hai
```

### 使用 StringBuilder 增量构建文本

在循环或复杂格式化场景中，应使用 `StringBuilder` 避免频繁分配中间字符串。`StringBuilder` 内部封装了 `bytes.ByteBuffer`，支持追加字符串与单个 `rune` 码点，并通过 `builder_string` 导出独立的不可变字符串副本。

```mio title="StringBuilder.mio"
yobu "kiso/string";

kaku sb = string.builder_with_capacity(32);
string.write_string(sb, "Mio ");
string.write_rune(sb, '澪');
string.write_rune(sb, '😀');

chant(string.builder_len(sb));      // 11（字节数）
chant(string.builder_string(sb));   // Mio 澪😀

// 清空内容并复用已分配容量
string.builder_reset(sb);
chant(string.builder_len(sb));      // 0
chant(string.builder_capacity(sb)); // >= 32
```

### 使用限制与平台说明

- **字节语义与文本粒度**：查找与索引函数均基于 UTF-8 字节偏移执行，不执行 Unicode 规范化（NFC/NFD）、大小写折叠或字素簇（Grapheme Cluster）切分。
- **构造器共享引用**：`StringBuilder` 内部持有的 `buffer` 字段遵循共享引用语义；若直接通过 `sb.buffer.data` 写入了非法 UTF-8 字节序列，后续调用 `builder_string(sb)` 将会触发运行时错误。
