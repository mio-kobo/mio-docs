> **版本说明：** 本页汇总 Mio V2.1（`Mio-2.1.2`）中 `kiso` 标准库与原生 AOT 工具链的完整公开符号表，准确区分 V2.1 新增模块、V2.0 既有模块的 V2.1 增量接口以及 V2.0 基础接口，并与各模块参考文档保持严格一一对应。

## Bunko API 索引

Bunko 是 Mio 的官方标准库集合（导入路径均以 `kiso/` 开头）。调用前需通过 `yobu "kiso/<模块路径>";` 导入对应包。关于各平台的宿主原语支持边界，请参考 [增量变化](/docs/v2.1/kiso/changes) 与 [验证与来源](/docs/v2.1/tooling/verification)。

### V2.1 新增标准库模块（5 个）

#### 1. `kiso/encoding/json` · [JSON 编解码](/docs/v2.1/kiso/encoding-json)

严格 RFC 8259 UTF-8 JSON 扁平节点索引树解析与渲染（纯 Mio 实现，支持 Web Playground）：

- **公开类型**：`Value`、`Document`
- **公开函数（6 个）**：`parse`、`member`、`text`、`integer`、`quote`、`render`

#### 2. `kiso/regexp` · [正则表达式](/docs/v2.1/kiso/regexp)

基于 Thompson NFA 的线性时间正则表达式编译与 Unicode 15.0 属性布尔匹配（纯 Mio 实现，支持 Web Playground）：

- **公开类型**：`State`、`Program`
- **公开函数（2 个）**：`compile`、`matches`

#### 3. `kiso/crypto/sha256` · [SHA-256 哈希摘要](/docs/v2.1/kiso/crypto-sha256)

标准 FIPS 180-4 SHA-256 单向哈希摘要与零拷贝区间计算（纯 Mio 实现，Darwin ARM64 原生后端自动映射硬件 SHA-256 指令）：

- **公开类型**：`Context`、`Tables`
- **公开函数（3 个）**：`context`、`sum_range`、`sum`

#### 4. `kiso/os` · [操作系统接口](/docs/v2.1/kiso/os)

命令行参数、环境变量、子进程控制、单调时钟、标准输入轮询与物理绝对路径解析（需宿主 OS 运行时支持）：

- **公开函数（17 个）**：`argument`、`arguments`、`environment`、`getenv`、`pid`、`exit`、`spawn`、`exec`、`spawn_test`、`monotonic_ms`、`stdin_ready`、`stdin_wait`、`remove`、`remove_dir`、`chmod`、`canonical_path`、`executable_path`

#### 5. `kiso/net/tcp` · [TCP 网络](/docs/v2.1/kiso/net-tcp)

阻塞式 IPv4 TCP 客户端连接、服务端监听、字节流读写与 `kiso/io` 流适配器（需宿主网络套接字运行时支持）：

- **公开类型**：`TcpError`、`IPv4Address`、`Connection`、`Listener`、`ConnectionResult`、`ListenerResult`、`ReadResult`、`WriteResult`、`UnitResult`
- **公开函数（12 个）**：`ipv4`、`connect`、`listen`、`listen_with_backlog`、`accept`、`read`、`write`、`write_all`、`close`、`close_listener`、`reader`、`writer`
