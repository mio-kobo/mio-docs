## Bunko API 索引

本索引按模块列出 Bunko 已公开的主要函数。基础模块以 `v2.0.0` 的 API 为起点；V2.1 新增加的函数和模块单独列出，避免把原本已有的接口误认为新功能。具体参数和返回值请阅读对应页面。

## V2.1 新增 API

| 模块 | 新增公开函数 | 详情 |
| --- | --- | --- |
| `kiso/encoding/json` | `parse`、`member`、`text`、`integer`、`quote`、`render` | [JSON](/docs/v2.1/kiso/encoding-json) |
| `kiso/regexp` | `compile`、`matches` | [正则表达式](/docs/v2.1/kiso/regexp) |
| `kiso/crypto/sha256` | `context`、`sum`、`sum_range` | [SHA-256](/docs/v2.1/kiso/crypto-sha256) |
| `kiso/string` | `trim_space` | [字符串](/docs/v2.1/kiso/string) |
| `kiso/fs` | `is_character_device` | [文件系统](/docs/v2.1/kiso/fs) |
| `kiso/math` | `fail` | [数学](/docs/v2.1/kiso/math) |
| `kiso/aot/sign` | `adhoc` | [AOT 签名](/docs/v2.1/kiso/aot-sign) |

`kiso/os` 也是 V2.1 新包。其公开接口包括 `argument`、`arguments`、`environment`、`getenv`、`spawn`、`exec`、`exit`、`pid`、`chmod`、`remove`、`remove_dir`、`canonical_path`、`monotonic_ms`、`stdin_ready`、`stdin_wait` 和用于工具链的 `spawn_test`；参见 [OS 接口](/docs/v2.1/kiso/os)。

原生工具链还有扩展的类型布局、lowering 和 Mach-O 接口，属于内部编译器 API，详见 [已有库的变化](/docs/v2.1/kiso/changes)。

### kiso/net/tcp

[TCP 网络参考与 Echo 教程](/docs/v2.1/kiso/net-tcp)

| 用途 | 公开函数 |
| --- | --- |
| 构造地址 | `ipv4` |
| 连接、监听和接入 | `connect`、`listen`、`listen_with_backlog`、`accept` |
| 读写和 I/O 适配 | `read`、`write`、`write_all`、`reader`、`writer` |
| 释放资源 | `close`、`close_listener` |

公开类型：`TcpError`、`IPv4Address`、`Connection`、`Listener`、`ConnectionResult`、`ListenerResult`、`ReadResult`、`WriteResult`、`UnitResult`。
