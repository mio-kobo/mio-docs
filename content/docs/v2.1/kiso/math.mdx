## 数学

数学标准库（`kiso/math`）提供圆周率常量、数值比较与限幅、溢出检查整数运算、浮点取整与分类以及运行时故障触发接口。

本包的泛型数学函数通过 `Number`、`Signed`、`Float` 约束保留调用方传入的具体数值类型，不会自动在整数、`float32` 和 `float64` 之间执行隐式精度转换。

### 导入包

> **网页运行说明：** 本页的 Playground 代码块均为独立程序，已分别加入所需的 `yobu` 导入语句。点击「运行」时不会继承页面中其他代码块的状态。

通过 `yobu "kiso/math";` 导入本包，随后使用 `math.函数名(...)` 调用。

```mio title="Stdlib.mio"
yobu "kiso/math";
```

### 数学常量与基础运算

`pi32`、`pi64`、`tau32`、`tau64` 均为编译期常量（`teisu`），分别提供单精度与双精度的 $\pi$ 与 $2\pi$；`min`、`max` 和 `clamp` 支持所有受约束的数值类型。

```mio title="MathBasics.mio"
yobu "kiso/math";

chant(math.pi64);
chant(math.tau32);
chant(math.min[int64](3, 8));
chant(math.clamp(12, 0, 10));
```

在上述示例中，`min` 遇相等的 `+0.0` 与 `-0.0` 时严格返回 `-0.0`，`max` 则返回 `+0.0`；若任一操作数为 `NaN`，`min` 与 `max` 均会传播 `NaN`。

### 浮点取整与分类

平方根、取整与特殊值分类函数接受 `float32` 或 `float64`（约束为 `Float`）。其中 `round` 在恰好处于两个整数正中间（半数）时遵循 IEEE 754 `ties-to-even`（四舍六入五成双）规则。

```mio title="MathFloat.mio"
yobu "kiso/math";

chant(math.sqrt[float64](144.0));
chant(math.floor[float32](-1.5));
chant(math.round[float64](2.5));
chant(math.round[float64](3.5));
chant(math.is_finite(1.0));
```

### 溢出检查与错误边界

`checked_abs`、`checked_gcd` 和 `checked_lcm` 在结果超出目标有符号整数表示范围（例如对 `int8(-128)` 或 `int64` 最小值求绝对值，或 `checked_gcd(MinInt64, 0)`）时安全返回 `mu`；不带 `checked_` 前缀的版本以及 `math.fail` 则会触发不可恢复的运行时错误并终止执行。

```mio title="MathChecked.mio"
yobu "kiso/math";

kaku overflow = math.checked_abs[int8](-128);
chant(overflow == mu);

kaku common = math.checked_lcm(21, 6);
moshi (common != mu) {
    chant(common);
}
```

### 公开常量（4 个）

| 常量    | 公开类型  | 含义                                        |
| ------- | --------- | ------------------------------------------- |
| `pi32`  | `float32` | 单精度圆周率 $\pi$（`3.1415927`）。         |
| `pi64`  | `float64` | 双精度圆周率 $\pi$（`3.141592653589793`）。 |
| `tau32` | `float32` | 单精度 $2\pi$（`6.2831855`）。              |
| `tau64` | `float64` | 双精度 $2\pi$（`6.283185307179586`）。      |

### 公开函数（18 个）

#### 1. 比较、限幅与绝对值（5 个）

| 函数          | 公开签名                                              | 功能与返回规则                                                                 |
| ------------- | ----------------------------------------------------- | ------------------------------------------------------------------------------ |
| `min`         | `min<T: Number>(left: T, right: T) -> T`              | 返回较小值；传播 `NaN`，相等正负零优先返回 `-0.0`。                            |
| `max`         | `max<T: Number>(left: T, right: T) -> T`              | 返回较大值；传播 `NaN`，相等正负零优先返回 `+0.0`。                            |
| `clamp`       | `clamp<T: Number>(value: T, lower: T, upper: T) -> T` | 将 `value` 限制在 `[lower, upper]` 区间；若 `lower > upper` 则触发运行时错误。 |
| `checked_abs` | `checked_abs<T: Signed>(value: T) -> T?`              | 计算有符号数绝对值；若发生最小负值溢出则返回 `mu`。                            |
| `abs`         | `abs<T: Signed>(value: T) -> T`                       | 计算有符号数绝对值；溢出时触发运行时错误。                                     |

#### 2. 浮点运算与分类（8 个）

| 函数        | 公开签名                                | 功能与返回规则                                   |
| ----------- | --------------------------------------- | ------------------------------------------------ |
| `sqrt`      | `sqrt<T: Float>(value: T) -> T`         | 计算平方根；负数返回 `NaN`，`-0.0` 返回 `-0.0`。 |
| `floor`     | `floor<T: Float>(value: T) -> T`        | 向负无穷方向取整。                               |
| `ceil`      | `ceil<T: Float>(value: T) -> T`         | 向正无穷方向取整。                               |
| `round`     | `round<T: Float>(value: T) -> T`        | 就近取整，半数采用 `ties-to-even`（偶数舍入）。  |
| `trunc`     | `trunc<T: Float>(value: T) -> T`        | 向零方向截断小数部分。                           |
| `is_nan`    | `is_nan<T: Float>(value: T) -> bool`    | 判断是否为 `NaN`。                               |
| `is_inf`    | `is_inf<T: Float>(value: T) -> bool`    | 判断是否为正无穷或负无穷。                       |
| `is_finite` | `is_finite<T: Float>(value: T) -> bool` | 判断是否为有限浮点数（非无穷且非 `NaN`）。       |

#### 3. 整数数论与诊断控制（5 个）

| 函数                                             | 公开签名                                           | 功能与返回规则                                                                               |
| ------------------------------------------------ | -------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| `checked_gcd`                                    | `checked_gcd(left: int64, right: int64) -> int64?` | 计算非负最大公约数（`gcd(0, 0) == 0`）；若结果等于 $2^{63}$ 无法用 `int64` 表示则返回 `mu`。 |
| `gcd`                                            | `gcd(left: int64, right: int64) -> int64`          | 计算非负最大公约数；无法用 `int64` 表示时触发运行时错误。                                    |
| `checked_lcm`                                    | `checked_lcm(left: int64, right: int64) -> int64?` | 计算非负最小公倍数（任一参数为 `0` 时返回 `0`）；溢出 `int64` 上限时返回 `mu`。              |
| `lcm`                                            | `lcm(left: int64, right: int64) -> int64`          | 计算非负最小公倍数；溢出时触发运行时错误。                                                   |
| `fail` <FeatureBadge status="new" since="2.1" /> | `fail(message: string) -> unit`                    | 立即触发带有指定错误文本的运行时失败并终止程序（不返回可捕获错误值）。                       |

### 完整示例

```mio title="MathFull.mio"
yobu "kiso/math";

chant(math.gcd(54, 24));
chant(math.lcm(6, 8));
chant(math.clamp(12, 0, 10));
chant(math.sqrt[float64](9.0));
chant(math.round[float32](2.5));
chant(math.checked_abs[int8](-128) == mu);
```

### 使用限制

- **内置泛型约束**：`Number`、`Signed`、`Float` 为编译器内置数值类型集合约束（其中 `Signed` 仅接受有符号整数与浮点类型，不接受 `uint8`、`uint16`、`uint32`），不支持用户自定义实现。
- **无隐式精度提升**：调用双参数泛型函数（如 `min`、`max`、`clamp`）时，所有参数必须具有完全相同的具体数值类型。
