## 开发工具

开发工具（Tooling）是用于编写、检查、编译、运行和维护 Mio 程序的一组工具。Mio 的源文件使用 `.mio` 扩展名，Mochi 字节码文件使用 `.mochi`。

V2.1 提供原生编译流程，并完善 CLI、语言服务器和测试工具。V2.0 与 V2.1 的部分命令行为不同；如果需要继续使用 Mochi VM，请先确认正在运行哪一个版本。

### 命令行工具

| 命令 | V2.0 正式 CLI | V2.1 开发版 CLI |
| --- | --- | --- |
| `mio check` | 源码静态检查 | 检查源码，不生成程序 |
| `mio build` | 默认生成 `.mochi` | 默认生成原生程序；可用 `--emit=mochi` |
| `mio run` | 编译源码并通过 VM 执行 | 编译临时原生程序并启动 |
| `mio exec` | 在 VM 中执行 Mochi | 将 Mochi 编译为原生程序后启动 |
| `mio disasm` | 查看 Mochi 字节码 | 查看 Mochi 字节码 |
| `mio test` | 运行测试 | 发现测试文件并在隔离进程中运行 |
| `mio lsp` | 启动 MioCore LSP | 启动 stdio LSP |

V2.1 的选项、输出与退出码仍可能调整。详细用法见 [Native CLI](/docs/v2.1/tooling/native-cli)。

### 从源码到原生程序 <FeatureBadge status="updated" since="2.1" />

V2.1 的原生编译流程将源码转换为对应平台的可执行文件。macOS ARM64、Linux AMD64 与 Windows AMD64 已有 CI 验证；后两者仍属实验性，正式支持情况见 [发行包说明](/docs/v2.1/tooling/distribution)。

不同版本的工具对 Mochi 格式的支持范围可能不同，详见 [Mochi 格式](/docs/v2.1/internals/mochi)。

### 编辑器与语言服务 <FeatureBadge status="updated" since="2.1" />

Mio 提供 VS Code 和 JetBrains 插件。V2.1 LSP 支持编辑器中未保存的内容、UTF-16 位置、文档缓存和诊断；重命名、格式化及语义 Token 等功能尚不能视为已完成。

插件安装方法见 [编辑器支持](/docs/v2.1/tooling/editors)，语言服务详情见 [LSP](/docs/v2.1/tooling/lsp)。如果想了解编译器与工具的内部实现，可继续阅读 [自托管工具链](/docs/v2.1/tooling/selfhost)。
