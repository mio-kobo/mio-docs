## 数组

`[]T` 为同质数组，`[a, b]` 从左到右求值。空字面量 `[]` 需要目标类型。索引必须是 `int64`，负数或越界为运行时错误。变量赋值、传参、返回共享后备数组，元素写入及长度变化对别名可见。动态操作由 [kiso/array](/docs/kiso/array) 提供，数组没有切片语法或相等运算。

```mio fixture="arrays"
yobu "kiso/array";
kaku original = [1, 2];
kaku alias = original;
alias[0] = 9;
array.push(alias, 3);
chant(original[0]);
chant(len(original));
kaku copied = array.clone(original);
copied[0] = 7;
chant(original[0]);
array.append_all(original, original);
chant(len(original));
array.truncate(alias, 1);
chant(len(original));
```

当前类型系统与 VM 支持数组嵌套；旧 LANGUAGE.md 的“不支持多维数组”已过时。嵌套使用数组的数组，共享内层引用，不承诺矩阵连续布局或 Native 后端完整支持。

```mio fixture="nested-array"
kaku values: [][]int64 = [[1], [2]];
kaku inner = values[0];
inner[0] = 9;
chant(values[0][0]);
chant(len(values));
```

## 结构体与枚举

用户类型名须以 ASCII 大写字母开头。`kata` 字段在声明中以 `;` 或 `,` 分隔；构造字段可以任意顺序，但不能缺失、重复或增加字段。已有字段不能通过赋值修改。若字段本身是数组或 Map，该集合仍具有共享可变语义；字段不可重新赋值不等于递归深不可变。当前无字段级私有可见性。

`sentaku` 变体可无数据或带数据。`awase` 必须完整覆盖每个变体且不重复；`baai` 绑定数量与关联数据一致，不支持通用模式匹配猜测。

```mio fixture="composites"
kata Pair<T> { first: T; second: T; }
sentaku Result<T, E> { Ok(T); Err(E); }
waza get(result: Result<int64, string>) -> int64 {
    awase (result) {
        baai Ok(value) { kaesu value; }
        baai Err(message) { chant(message); kaesu 0; }
    }
}
kaku pair = Pair[int64] { second: 22, first: 20 };
chant(pair.first + pair.second);
kaku result: Result<int64, string> = Result.Ok(7);
chant(get(result));
```

## Map

类型写作 `Map<K, V>`，构造写作 `Map[K, V]()`；目标类型明确时可用 `Map()`。键只支持整数、`bool` 和 `string`；浮点、数组和复合对象不能作为键。Map 赋值和传参共享修改。`map[key] = value;` 插入或更新；读取返回 `V?`，缺键为 `mu`。当前此参考不承诺不存在于源码的遍历、删除或长度 API。

```mio fixture="maps"
kaku entries = Map[string, int64]();
entries["answer"] = 42;
kaku alias = entries;
alias["answer"] = 43;
kaku answer = entries["answer"];
moshi (answer != mu) { chant(answer); }
chant(entries["missing"] == mu);
```

证据：`internal/typecheck/type.go` 的 `ArrayOf`、`definitions.go`、`checker.go` 与 `internal/value/`、`internal/vm/`；拒绝字段赋值和嵌套数组成功均有 fixture。
