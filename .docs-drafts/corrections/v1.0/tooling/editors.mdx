## 可重现的开发方式

用支持 UTF-8 的编辑器保存 `.mio`，在终端使用本版 `mio check main.mio` 和 `mio run main.mio`。诊断格式和执行步骤见 [CLI](/docs/v1.0/tooling/cli)。语法着色和文件关联属于编辑器配置，不能据此推断语义补全、引用或跨文件分析可用。

## 语言服务限制

V1 CLI 没有 `mio lsp`。配置一个调用该命令的编辑器服务器不会使服务出现，不能用 V2 的能力列表承诺 V1 用户会得到相同体验。也不能把插件当前版本与核心 CLI 的版本字符串视为同一版本。

若使用独立插件，应依据其真实说明核对核心要求。此页不提供未经实测的 Marketplace 版本或兼容安装承诺；手工 CLI 流程不依赖插件。
