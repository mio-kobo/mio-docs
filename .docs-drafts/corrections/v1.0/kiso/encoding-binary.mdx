固定宽度大小端与 LEB128 编码；使用 []uint8。本版本没有游标 Reader、Writer 和 U64。失败先检查 error；结果 value 可能是占位值，不能忽略错误。

支持范围：本页示例通过 Go 引导 CLI / Mochi VM 验证；错误分支覆盖范围见 [验证报告](/docs/v1.0/tooling/verification)，不表示每个函数的每条分支均实测。Native AOT 与纯 Mio 后端需按 [当前阶段](/docs/v1.0/internals/native-aot) 单独评估。

### read_u8

```text
koukai waza read_u8(data: []uint8, offset: int64) -> U8Result
```

参数：`data`：输入字节数组；是否复制见返回语义；`offset`：从起点计数的字节偏移，起点为 0。

从 data 的 offset 按指定端序读取固定宽度值，返回对应 Result；负 offset 为 InvalidOffset，剩余不足为 InsufficientData，不复制整个输入。

### write_var_u32

```text

```

参数：`value`：本次操作的输入值，返回语义及限制如下。

将 value 编码为新 LEB128 数组并包装为 BytesResult（data 为编码、error=mu）；u32 为无符号、i64 为 DWARF 有符号，不是 ZigZag。

### read_var_u32

```text

```

参数：`data`：输入字节数组；是否复制见返回语义；`offset`：从起点计数的字节偏移，起点为 0。

## 完整示例

```mio title="binary.mio"
yobu "kiso/array";
yobu "kiso/encoding/binary";
kaku data = array.make[uint8](8, uint8(0));
kaku error = binary.write_i64_be(data, 0, -42);
chant(error == mu);
kaku result = binary.read_i64_be(data, 0);
chant(result.value);
kaku bad = binary.read_u32_le(data, 6);
chant(bad.error != mu);
```

预期 stdout：

```text title="output"
hai
-42
hai
```

读取 Result 时应先判断 error；本例已知写入成功，再读同一有效范围。V1 只含本页列出的固定宽度和变长编码，不含 V2 的流式 Reader/Writer。
