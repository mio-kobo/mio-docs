## 如何读 API

每个函数先列原始签名，再说明输入、返回、错误和存储共享。`unit` 表示没有普通返回值；`T?` 用 `mu` 表示缺失；`Error?` 返回 `mu` 通常表示成功，返回非空错误表示失败。带 `error` 的 Result 应先检查错误再读有效负载，不能把默认零值当成功结果。

长度和偏移须看单位：数组按元素，字节与路径/字符串索引规则按各包说明。`clone` 的独立存储不必然意味着递归深复制。动态分配还受 VM 资源预算影响，返回错误值的 API 不保证能捕获一切资源错误。
