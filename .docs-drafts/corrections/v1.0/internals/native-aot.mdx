## 本版执行方式

`mio run` 在 Go VM 内执行字节码；`mio build` 把字节码保存为 Mochi 文件，仍需 `mio exec` 加载和运行。Mochi 容器不是 ARM64 Mach-O，也不是独立原生可执行文件。

## 版本边界

Go AOT、纯 Mio lowering 和原生 GC 是后续开发快照中的实现。源码目录、阶段记录和测试均须查对应版本，不能因为后续开发仓库已有这些文件就声称 V1 已提供它们。M17e 尚未验收，M18 尚未启动；本页不发布未来功能承诺。

本轮按精确提交取归档并验证 VM 程序，未执行原生程序或自举。源文件存在与否也保存在完整归档清单；没有把不在此版本中的命令列为未完成安装步骤。
