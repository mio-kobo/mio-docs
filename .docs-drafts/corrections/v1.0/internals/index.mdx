Mochi 字节码文件不是原生可执行文件。Go VM 的内存由宿主管理；本标签没有后续开发版的 Native Runtime。本教程的 VM 程序通过不证明 Native 后端接受相同程序。

M17e 尚未验收，M18 尚未启动；没有本版本已发布纯 Mio 原生自举或 WebAssembly Playground 的结论。每项状态都须结合具体后端、提交和实际执行证据。
