## 学习目标与前置

区分字节长度、Unicode 标量值和字符串构造。 前置：[上课：数组与空值](/docs/v2.0.0/learn/collections)。本章使用固定版本的 Go 引导 CLI / Mochi VM。

## 为什么需要

一个汉字和三个 ASCII 字母看起来是四个字符，但 UTF-8 字节数为六。文件、网络或二进制接口处理字节，文本界面往往关心 Unicode 标量值；混用这两个单位会造成索引错误。

## 保存与运行

在安装页的 `项目` 目录保存为 `strings.mio`，使用该版本构建的 CLI 和同一份 `bunko/`：

```sh
mio check strings.mio
mio run strings.mio
```

`check` 成功报告 `check passed`。下面是完整程序与 `run` 的标准输出，末尾包含换行。

```mio title="strings.mio"
yobu "kiso/string";
yobu "kiso/utf8";
kaku text = "澪Mio";
chant(string.byte_len(text));
chant(string.rune_count(text));
kaku data = string.to_bytes(text);
chant(len(data));
chant(utf8.valid(data));
kaku builder = string.new_builder();
string.write_string(builder, text);
string.write_string(builder, "!");
chant(string.builder_string(builder));
```

```text title="output"
6
4
6
hai
澪Mio!
```

## 逐段理解

前两条输出分别是字节数与标量值数。`string.to_bytes` 复制字符串内容为独立 `[]uint8`，因此可以用数组内置 `len`。`utf8.valid` 检查字节序列是否合法，返回 `bool`，打印为 `hai`。

Builder 收集两段字符串，再生成字符串结果。字符串不可变，拼接不能使用 `+`；本例通过真实库接口构造。Builder 的副本共享内部缓冲区，不能当作独立副本随意修改。

`rune_count` 数的是 Unicode 标量值，不是用户感知的字素簇；组合音符与 emoji 可能含多个标量。`len(text)` 不接收字符串，字节偏移也不能直接当作第几个汉字。

## 练习

把字符串改为 `"Mio"`，保留其余代码。 先预测再执行 `check` 与 `run`，预期逐行输出：

```text title="exercise-output"
3
3
3
hai
Mio!
```

## 常见陷阱与核对

`len` 只接受数组，字符串请用 `string.byte_len`；`rune_count` 不等于字素簇数量。Builder 的别名共享缓冲区，独立文本结果须通过 `builder_string` 取得。将字节转回文本时应使用 `from_utf8` 并检查可空结果。
