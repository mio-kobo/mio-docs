Mochi 字节码文件不是原生可执行文件。Go VM 的内存由宿主管理；Native Runtime 的 Heap、根协议和 GC 是另一套执行环境。本教程的 VM 程序通过不证明 Native 后端接受相同程序。

M17e / M18 已有本地核心验收证据，尚未正式发布。WebAssembly Playground 无发布支持证据。每项状态都须结合具体后端、提交和实际执行证据。
