**V2.0.0 RC4 审阅快照（尚未发布）**，来源锁见 `verification/v2.0.0/rc4-source-manifest.json`。**V1.0 不提供本包**。公开声明不代表稳定 API；本页仅承诺此快照已有声明及明确列出的验证。

内部表示分析，不是用户级反射接口。TypeAnalysis 保存分析 arena、槽位及控制流块的表示约束。节点编号必须来自该次分析，查询函数不会为任意编号提供安全包装。

## 函数

### type_kind

```text
koukai waza type_kind(analysis: TypeAnalysis, node: int64) -> int64
```

参数：`analysis`：同一次分析产生的 TypeAnalysis；`node`：该分析内部有效节点索引，不是任意用户编号。

返回节点根的表示类别整数，对照本页 type_* 常量。 节点/数组内部不变式被破坏可能直接触发运行时越界；本包没有通用错误 Result 包装。
