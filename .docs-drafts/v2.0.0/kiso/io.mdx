## 函数

签名中的参数名及类型保持源码原样；下文说明参数含义、返回值及错误。除明确返回错误值的路径外，数组分配、转换和 VM 指令预算等资源限制仍可能导致运行时错误。

### read

```text
koukai waza read(reader: Reader, destination: []uint8, offset: int64, length: int64) -> ReadResult
```

参数：`reader`：提供读取回调的 Reader；`destination`：接收写入的现有目标数组；`offset`：从起点计数的字节偏移，起点为 0；`length`：本次读写的字节数量。

检查 destination 的 offset/length 后调用 reader.read；非法区间返回 InvalidArgument。count 是读取字节数，可同时 eof=hai。

### write

```text
koukai waza write(writer: Writer, source: []uint8, offset: int64, length: int64) -> WriteResult
```

参数：`writer`：提供写入回调的 Writer；`source`：读取或追加的来源数组；`offset`：从起点计数的字节偏移，起点为 0；`length`：本次读写的字节数量。

检查 source 的 offset/length 后调用 writer.write；非法区间返回 InvalidArgument，允许部分写入。

### read_full

```text
koukai waza read_full(reader: Reader, destination: []uint8, offset: int64, length: int64) -> ReadResult
```

参数：`reader`：提供读取回调的 Reader；`destination`：接收写入的现有目标数组；`offset`：从起点计数的字节偏移，起点为 0；`length`：本次读写的字节数量。

反复读取直到 length；保留已读取 count，提前 EOF 返回 UnexpectedEOF，无进展返回 NoProgress，非法 count 返回 InvalidArgument。长度 0 不调用 Reader，eof=iie。

### write_all

```text
koukai waza write_all(writer: Writer, source: []uint8, offset: int64, length: int64) -> WriteResult
```

参数：`writer`：提供写入回调的 Writer；`source`：读取或追加的来源数组；`offset`：从起点计数的字节偏移，起点为 0；`length`：本次读写的字节数量。

反复写完 source 指定区间；保留 count，无进展返回 NoProgress，非法区间/回调 count 返回 InvalidArgument；长度 0 成功。

### copy_stream

```text
koukai waza copy_stream(reader: Reader, writer: Writer) -> CopyResult
```

参数：`reader`：提供读取回调的 Reader；`writer`：提供写入回调的 Writer。

使用固定 32768 字节 buffer 从 reader 复制到 writer；返回已写 count 与错误，内存与执行成本受资源限制。

### reader_from_bytes

```text
koukai waza reader_from_bytes(source: []uint8) -> Reader
```

参数：`source`：读取或追加的来源数组。

返回共享 source 存储、独立游标的 Reader；后续外部修改可见，读取推进游标，到末尾 eof=hai。

### writer_to_buffer

```text
koukai waza writer_to_buffer(buffer: bytes.ByteBuffer) -> Writer
```

参数：`buffer`：待操作共享字节缓冲区。

返回将 source 指定区间追加到 buffer 的 Writer；返回追加字节数，外部 buffer 别名可见。

## 完整示例

```mio fixture="io"
yobu "kiso/io";
yobu "kiso/bytes";
kaku source: []uint8 = [65, 66, 67];
kaku reader = io.reader_from_bytes(source);
kaku buffer = bytes.new_buffer();
kaku result = io.copy_stream(reader, io.writer_to_buffer(buffer));
chant(result.count);
chant(result.error == mu);
chant(bytes.equal(buffer.data, source));
```

预期 stdout（逐字节匹配，末尾有换行）：

```text title="output"
3
hai
hai
```
