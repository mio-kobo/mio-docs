**版本范围：V2.0.0 · RC4 审阅快照（尚未发布）**。来源为 RC4 的 source-manifest 与包内 BUILD-INFO；HEAD 加未提交来源共同构成候选，不能只检出 HEAD。正文示例默认走包内 CLI / VM。

严格 ASCII 文本转换，不清理空白。浮点接受十进制、小数、指数及 NaN、Infinity、+Infinity、-Infinity，使用 roundTiesToEven，允许下溢到带符号零。

支持范围：本页示例通过 Go 引导 CLI / Mochi VM 验证；错误分支覆盖范围见 [验证报告](/docs/v2.0.0/tooling/verification)，不表示每个函数的每条分支均实测。Native AOT 与纯 Mio 后端需按 [当前阶段](/docs/v2.0.0/internals/native-aot) 单独评估。

## 函数

签名中的参数名及类型保持源码原样；下文说明参数含义、返回值及错误。除明确返回错误值的路径外，数组分配、转换和 VM 指令预算等资源限制仍可能导致运行时错误。

### parse_int

```text
koukai waza parse_int(value: string) -> int64?
```

参数：`value`：待解析的 ASCII 文本，不预先裁剪空白。

解析 value 的 ASCII 十进制 int64，可带 + 或 -；空白、非法字符或越界返回 mu。

### parse_uint

```text
koukai waza parse_uint(value: string) -> uint32?
```

参数：`value`：待解析的 ASCII 文本，不预先裁剪空白。

解析 value 的 ASCII 十进制 uint32，可带 +，拒绝 -；非法或越界返回 mu。

### format_int

```text
koukai waza format_int(value: int64) -> string
```

参数：`value`：需要格式化为文本的数值或布尔值。

返回 value 的十进制文本，覆盖 MinInt64。

### format_uint

```text
koukai waza format_uint(value: uint32) -> string
```

参数：`value`：需要格式化为文本的数值或布尔值。

返回 value 的无符号十进制文本。

### parse_bool

```text
koukai waza parse_bool(value: string) -> bool?
```

参数：`value`：待解析的 ASCII 文本，不预先裁剪空白。

只接受 value 为 hai 或 iie，其他文本返回 mu。

### format_bool

```text
koukai waza format_bool(value: bool) -> string
```

参数：`value`：需要格式化为文本的数值或布尔值。

返回 hai 或 iie。

### parse_float64

```text
koukai waza parse_float64(value: string) -> float64?
```

参数：`value`：待解析的 ASCII 文本，不预先裁剪空白。

将 value 舍入为 binary64；非法、上溢或输入超过 10000 字节返回 mu。

### parse_float32

```text
koukai waza parse_float32(value: string) -> float32?
```

参数：`value`：待解析的 ASCII 文本，不预先裁剪空白。

直接将 value 舍入为 binary32；非法、上溢或输入超过 10000 字节返回 mu。

### format_float64

```text
koukai waza format_float64(value: float64) -> string
```

参数：`value`：需要格式化为文本的数值或布尔值。

返回 value 最短往返十进制，保留负零文本；NaN 文本不保留 payload。

### format_float32

```text
koukai waza format_float32(value: float32) -> string
```

参数：`value`：需要格式化为文本的数值或布尔值。

返回 value 最短往返十进制，保留负零文本；NaN 文本不保留 payload。

## 完整示例

```mio fixture="convert"
yobu "kiso/convert";
kaku number = convert.parse_int("-42");
moshi (number != mu) { chant(number); }
chant(convert.parse_uint("-1") == mu);
chant(convert.parse_bool("true") == mu);
chant(convert.format_bool(hai));
kaku value = convert.parse_float32("1.25");
moshi (value != mu) { chant(convert.format_float32(value)); }
```

预期 stdout（逐字节匹配，末尾有换行）：

```text title="output"
-42
hai
hai
hai
1.25
```
